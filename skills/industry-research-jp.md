# 日本株の業界・産業チェーン研究

## 研究目標

`$ARGUMENTS` の業界について、需要の根因から産業チェーン、利益プール、供給制約、東証上場企業へつながる投資論理を検証する。市場規模の大きさだけで候補を選ばない。

## ステップ1：投資論理チェーンを作る

### 1.1 論理チェーン

```text
構造変化 → 需要・供給の変化 → 制約・交渉力 → 利益プール → 対象企業の売上・利益・CF
```

各矢印について、因果、時間軸、数量、反証条件を示す。

### 1.2 各段階を検証する

- 需要が循環か構造か。
- 政策、人口、技術、更新周期、顧客投資のどれが駆動するか。
- 供給を増やす期間、認証、設備、人材、原材料の制約。
- 値上げが誰の利益になるか。
- 既に起きた検証事象と、まだ期待だけの部分。

### 1.3 反証

需要鈍化、供給増加、技術代替、顧客内製化、規制変更、設備過剰が論理を壊す条件を置く。

## ステップ2：産業チェーン全体を描く

### 2.1 構造

原材料、部品、装置、製造、物流、販売、導入、保守、最終顧客へ分解する。

### 2.2 各工程の事業特性

| 工程 | 顧客 | 課金 | 粗利・資本集約 | 競争 | 参入障壁 | 循環性 |
|---|---|---|---|---|---|---|

### 2.3 制約と利益プール

供給者数、稼働率、納期、受注残、在庫、値上げ、代替可能性を確認し、制約の強さをS・A・B・Cで表示する。

## AI調査バイアス

- 開示が豊富な大型企業を過大評価しない。
- 話題性の高い工程を利益プールと誤認しない。
- 日本語情報だけで国内市場の閉鎖性を過大評価しない。
- 海外企業は競合・顧客・供給網の事業文脈に限定する。
- 未上場の重要企業は産業構造として扱えるが、公開株候補へ混ぜない。

## ステップ3：東証上場企業を走査する

JPX上場会社情報と会社IRから、東証プライム・スタンダード・グロースの内国普通株を列挙する。

各社について次を収集する。

- 証券コード、市場区分、対象事業の売上・利益構成。
- 顧客、価格、数量、能力、受注、設備投資。
- 時価総額、株式数、PER、PBR、FCF、ROIC。
- 政策保有株、親子上場、支配株主等のガバナンス。
- 産業チェーンの位置と利益プールへの感応度。

| 会社 | コード | 工程 | 対象利益比率 | 強み | 主なリスク | 情報充実度 |
|---|---|---|---:|---|---|---|

## ステップ4：工程別の有力企業を深掘りする

### 4.1 事業の本質

誰が何に払い、何が反復し、成長にどれだけ再投資が必要かを説明する。

### 4.2 競争優位

価格決定力、切替費用、規模、コスト、技術、認証、希少資産を証拠付きで評価する。

### 4.3 逆向き思考

業界が成長しても対象企業が儲からない経路、最強の競合、代替技術、設備過剰を示す。

### 4.4 経営・ガバナンス

設備投資、買収、還元、政策保有株、親子上場、少数株主保護を確認する。

### 4.5 円建て評価

`skills/financial-data-jp.md` と共通ツールを使い、同一基準日・同一会計口径で比較する。

```bash
python tools/financial_rigor.py --locale ja verify-market-cap --price {株価} --shares {株式数} --reported {時価総額} --currency JPY
python tools/financial_rigor.py --locale ja three-scenario --price {株価} --eps {EPS} --shares {株式数_億株} --growth {強気} {基準} {弱気} --pe {強気PER} {基準PER} {弱気PER} --currency JPY
```

### 4.6 推奨度

事業品質、競争優位、資本効率、経営、評価、情報品質を1〜5で採点し、価格条件を付ける。

## ステップ5：業界リスク

- 景気、金利、為替、原材料、エネルギー、災害。
- 規制、補助金、許認可、環境負担。
- 技術代替、標準変更、顧客内製化。
- 供給過剰、価格競争、在庫調整。
- 人材、品質、サイバー、地政学的な供給途絶。

歴史的な類似局面を使う場合は、共通点と相違点を明記する。

## ステップ6：長期構造変化を判定する

変化が5年以上続くか、不可逆性があるか、価値獲得主体が安定しているか、再投資利益率が維持できるかを判定する。

## ステップ7：候補の組み合わせとシグナル

候補は役割の違いで整理する。

- 中核：確実性と財務耐久性を重視。
- 補完：評価余地または別工程への分散。
- 選択肢：不確実だが非対称な上昇余地。

テーマ全体への比率上限、買付・追加・縮小・撤回シグナルを示す。個別のポジション比率はユーザーの制約がある場合だけ提案する。

## ステップ8：業界意思決定レポート

1. 業界要約と一文結論。
2. 投資論理チェーン。
3. 産業チェーン・利益プール・制約地図。
4. 東証候補一覧。
5. 有力候補の詳細比較。
6. 最強の反対意見。
7. 三情景と行動条件。
8. 先行指標と次回更新条件。
9. 情報充実度と制約。

`reports/{業界}/{業界}-industry-research-{YYYYMMDD}.md` に保存し、次を実行する。

```bash
python tools/report_audit.py --locale ja extract --market jp --report {レポート}
python tools/report_audit.py --locale ja verdict --market jp --results '<照合済みJSON>' --report {レポート名}
```

監査不合格ならドラフトとする。
