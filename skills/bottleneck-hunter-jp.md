# 日本株の供給制約・ボトルネック探索

## 目的

成長テーマそのものではなく、需要増に対して短期に供給を増やせない工程、設備、材料、認証、人材、物流を見つけ、価格決定力と利益増分を獲得できる東証上場企業を探す。

## 手順

1. `date` で基準日を確定する。
2. 需要の構造要因、数量、更新周期、政策、代替可能性を調べる。
3. 産業チェーンを原材料、部品、装置、製造、物流、販売、保守に分解する。
4. 各工程について増産期間、認証期間、設備投資、歩留まり、供給者数、在庫、代替技術を確認する。
5. 制約がある工程でも、利益を獲得する主体が誰かを特定する。単なる売上増と価格決定力を区別する。
6. 投資候補は東証プライム・スタンダード・グロースの内国普通株に限定する。
7. 候補企業ごとに制約への売上感応度、競争優位、増産余地、顧客集中、循環性、現在評価を確認する。
8. 制約解消、顧客の内製化、技術代替、設備過剰、規制変更を終了条件として置く。

海外企業は顧客、競合、供給網の説明に必要な場合だけ扱う。国外上場銘柄を候補一覧へ加えず、国外株価や評価倍率を取得しない。

## 証拠の優先順位

- 会社IR、有価証券報告書、決算短信、適時開示
- 官公庁、業界団体、設備投資・生産能力の公式統計
- 顧客と供給者双方の一次資料
- 信頼できる業界報道

市場規模の大きさだけでボトルネックと判定しない。納期、稼働率、値上げ、受注残、設備リードタイムのうち二つ以上を確認する。

## 候補評価表

| 項目 | 確認内容 |
|---|---|
| 制約の強さ | 増産リードタイム、代替困難性、認証 |
| 利益獲得 | 値上げ、製品構成、限界利益 |
| 持続期間 | 解消投資、参入、技術代替 |
| 企業感応度 | 対象事業の売上・利益構成 |
| 財務余力 | 設備投資、負債、営業CF |
| 評価 | 円建て時価総額、倍率、三情景 |

データは `skills/financial-data-jp.md`、計算は `financial_rigor.py --locale ja` を使う。

## 出力

需要信号、産業チェーン図、真の制約、東証候補、候補別採点、最有力1〜3社、否定条件、次回観測日を日本語でまとめる。候補がなければ無理に銘柄を出さない。
