# サプライチェーン・ボトルネック・ハンター：AI駆動のグローバル産業チェーン・ボトルネック裁定取引

`$ARGUMENTS` のメガトレンドについて、サプライチェーンのボトルネックをスキャンし、裁定取引の機会を発掘する。

## 中核となる考え方

「AIはどの株式を推奨するか」ではなく、「このトレンドが拡大し続けた場合、どの工程が最初に不足するか」を問う。

従来の投資調査は、業界大手や既知の有望分野を注視する。このシステムは逆のアプローチを取る。**物理的なサプライチェーンの急所から出発し、注目されていないものの、ひとたび供給が途絶えると業界全体が停止を余儀なくされる企業を探す**。

超過収益の源泉：第1層のボトルネック（GPU、HBM、電力）は、すでに十分織り込まれている。本当のアルファは**第2層、第3層**にある――光モジュール、レーザー、InP基板、SOIウェハ、エピタキシャル成長装置、ウェハレベルテスト、ICパッケージ基板、特殊ガラス繊維などである。

## ステップ1：メガトレンドの確認

### 1.1 トレンドの選定基準

一過性の小さなテーマに幻想を抱かず、以下の条件をすべて満たすメガトレンドだけを追う。

| 基準 | 要件 | 検証方法 |
|------|------|---------|
| 持続性 | 少なくとも3～5年間の確実な成長 | 業界予測、設備投資計画を検索 |
| 物理性 | 実際のハードウェア・材料・設備の建設が必要 | 「ソフトウェアのアップグレード」と「物理的な増設」を区別 |
| 規模 | 世界の設備投資が年間500億米ドル超 | 大手企業の設備投資ガイダンスを検索 |
| 加速性 | 需要成長率が供給側の増産速度を上回る | 需要成長率と生産能力拡張計画を比較 |

### 1.2 現在追跡中のメガトレンド一覧

実行のたびに更新する。初期リスト：

1. **AIインフラ構築** — データセンター、GPUクラスター、ネットワーク相互接続、電力
2. **エネルギー転換** — 原子力発電の再稼働、電力網の高度化、エネルギー貯蔵
3. **防衛の近代化** — 西側諸国の国防費増加サイクル、サプライチェーン再構築
4. **半導体の再工業化** — 米国・欧州・日本の補助金による工場建設、装置・材料のボトルネック
5. **宇宙経済** — 衛星インターネット、打ち上げ頻度の急増

ユーザーが具体的なトレンド（例：「AIインフラ」）を指定した場合は、そのトレンドだけに焦点を当てる。

## ステップ2：サプライチェーンの物理的な分解

### 2.1 階層別の分解フレームワーク

**概念レベルにとどまらず、物理的な実体まで分解する**。

```
Layer 0（最終用途）：最終製品／サービス
    │
Layer 1（中核部品）：すでに市場から十分注目されている中核ハードウェア
    │                 ⬆ 十分に織り込まれており、アルファは限定的
    │─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─
    │                 ⬇ 注目度が低く、アルファが集中する領域
    │
Layer 2（サブコンポーネント／材料）：中核部品を支える部品と材料
    │
Layer 3（上流の装置／原料）：サブコンポーネントの製造に必要な装置と原材料
    │
Layer 4（インフラ）：電力、冷却、土地、人材、認証
```

### 2.2 AIインフラを例とした分解テンプレート

```
Layer 0：AIモデルの学習／推論サービス
Layer 1：GPU／アクセラレーター、HBMメモリ、サーバー、データセンター
Layer 2（重点スキャン領域）：
  ├─ ネットワーク相互接続：光モジュール、光ファイバー、スイッチチップ、銅ケーブル
  ├─ 光通信の中核：レーザー（EML／VCSEL／CW）、変調器、光検出器
  ├─ 半導体材料：InP基板、GaAs基板、SOIウェハ、SiC基板
  ├─ 先端パッケージング：CoWoSパッケージ基板、HBM TSV、ABF基板用フィルム
  ├─ PCB／パッケージ基板：高周波・高速PCB、ICパッケージ基板、特殊ガラス繊維クロス
  ├─ テスト：ウェハレベルテスト（プローブカード）、バーンインテスト、ATE
  ├─ 放熱／冷却：液冷システム、CDU、液浸冷却液
  └─ 電力接続：バスダクト、UPS、配電盤、変圧器
Layer 3：
  ├─ エピタキシャル成長装置：MOCVD、MBE
  ├─ 露光／エッチング：特殊波長露光、InPエッチング
  ├─ 原材料：高純度金属（インジウム、ガリウム、ゲルマニウム）、特殊ガス、ターゲット材
  └─ 認証／規格：MSA規格、Telcordia認証
Layer 4：
  ├─ 電力：原子力発電、天然ガス発電、送変電
  ├─ 冷却水／放熱インフラ
  └─ データセンター用地／許認可
```

## ステップ3：ボトルネックの特定――「急所」を探す

### 3.1 ボトルネック判定の6基準

Layer 2～3の各工程について、項目ごとに評価する。

| # | 基準 | 質問 | スコア |
|---|------|------|------|
| 1 | **供給の集中度** | 世界のサプライヤーは3社以下か？ | 🔴 2社以下 / 🟡 3～5社 / 🟢 5社超 |
| 2 | **増産リードタイム** | 生産能力の増強にどの程度かかるか？ | 🔴 2年超 / 🟡 1～2年 / 🟢 1年未満 |
| 3 | **代替の難易度** | 他の技術・材料で代替できるか？ | 🔴 代替不可 / 🟡 一部代替可能 / 🟢 容易に代替可能 |
| 4 | **生産能力稼働率** | 現在の生産能力稼働率は？ | 🔴 90%超 / 🟡 70～90% / 🟢 70%未満 |
| 5 | **需要成長率** | 下流の需要成長率は？ | 🔴 年50%超 / 🟡 年20～50% / 🟢 年20%未満 |
| 6 | **顧客認定期間** | 新規サプライヤーの認定にどの程度かかるか？ | 🔴 1年超 / 🟡 6～12カ月 / 🟢 6カ月未満 |

**ボトルネック評価**：
- 🔴が4個以上 → **S級ボトルネック**（単一障害点レベル、最優先）
- 🔴が3個 → **A級ボトルネック**（深刻な制約）
- 🔴が1～2個 → **B級ボトルネック**（圧力はあるが制御可能）
- 🔴なし → ボトルネックではないため除外

## ステップ4：企業の選定――ボトルネックから投資候補へ

### 4.1 S級・A級の各ボトルネックについて、関連する上場企業をすべて特定する

検索方法：
- WebSearch `"{ボトルネック工程} supplier listed company"`
- WebSearch `"{ボトルネック工程} manufacturer stock"`
- WebSearch `"{ボトルネック製品} market share company"`

### 4.2 初期スクリーニング基準（迅速な絞り込み）

| 基準 | 要件 | 理由 |
|------|------|------|
| 上場状況 | 上場済み（中国A株／香港／米国／日本／台湾／欧州） | 取引可能 |
| ボトルネック事業の比率 | 売上高の30%超がボトルネック工程によるもの | 事業の純度 |
| 時価総額 | 100億米ドル未満を優先 | 大型株はすでに十分織り込まれている |
| 流動性 | 1日平均売買代金100万米ドル超 | 売買可能性 |

### 4.2.1 バリュエーション確認（必須。省略不可）

**ボトルネックが実在すること ≠ 投資機会であること。** 各社についてPSR、PERを必ず計算し、レポートに記載する。以下の複合条件で、バリュエーションが先行しすぎていないかを判断する。

#### バリュエーションの赤信号（いずれか1つを満たす → シグナル強度の上限は★★、「⚠️ バリュエーションの先行」と明記）

1. **時価総額 > TAMの20%**：企業の時価総額が、同社の獲得可能な市場規模の20%を超えており、成長期待が過度に織り込まれていることを示す
2. **PSR > 30倍、かつ売上高成長率 < 100%**：高いバリュエーションに対して成長率が不十分。成長率が100%を超える企業はPSRの赤信号を免除できるが、それでも「⚠️ 高いバリュエーションを維持するには高成長の継続的な検証が必要」と明記する
3. **時価総額 > 5年後の楽観的な売上高予測の10倍**：最も楽観的な仮定がすべて実現しても、現在の価格設定はなお高すぎる
4. **増資後60日以内に株価が2倍**：センチメント主導の特徴が明確なため、シグナル強度を1段階引き下げる

#### バリュエーションの黄信号（追加説明が必要。なければ格下げ）

1. **赤字 + PSR > 15倍**：★★★への選定は可能だが、黒字化への道筋と時期を必ず説明する
2. **PSRが黒字の同業他社の5倍以上**：プレミアムの根拠（市場シェア、成長率の差、参入障壁の差）を必ず説明する
3. **PER > 80倍**：PEGレシオを計算し、成長率がその水準を正当化できるか説明する

#### バリュエーションの青信号（加点要素）

- PSR < 10倍、かつ売上高が成長中 → シグナル強度を1段階引き上げ可能
- PER < 30倍、かつ経済的な堀がある → 「バリュエーションに安全余裕あり」と明記

#### バリュエーションの妥当性検証（必須）

各投資候補について、次の問いに答える。「現在の時価総額で買い、最も楽観的なシナリオがすべて実現し、10年後にPER 25倍で売却した場合、年率リターンはいくらか？」 年率リターンが10%未満の場合は、「現在の価格に安全余裕はない」と明記する。

**注意**：バリュエーション確認の目的は、「PSR 100倍の赤字企業」を推奨するといった明白な誤りを防ぐことであり、高いバリュエーションのアーリーステージ企業をすべて排除することではない。重要なのは、成長率、TAM、競争環境が現在のバリュエーションを正当化できるかである。一律に判断せず、具体的に分析する必要がある。

**台湾株のデータ取得**：サプライチェーンのスキャンでは台湾株（2330、3661などの4桁コード）が頻繁に該当する。その株価／PER／時価総額／月次売上高は、`python3 tools/twstock_data.py` を使用して統一的に取得する（FinMindデータソース。使用方法は `skills/financial-data.md` の台湾株セクションを参照）。台湾株は毎月10日までに前月の売上高を開示することが義務付けられており、月次売上高の前年同期比は、ボトルネックにおける「数量・価格の同時上昇」を検証する最も早い公開シグナルである。

## ステップ5：クロスチェック――1つのストーリーだけを信じない

### 5.1 順方向の検証

| 検証項目 | 質問 | 検索方法 |
|--------|------|---------|
| 顧客による検証 | 大手顧客と契約済みか／採用済みか？ | 企業開示、顧客の決算における言及を検索 |
| 売上高による検証 | ボトルネックは売上高成長にすでに表れているか？ | 直近2～3四半期の決算を検索 |
| 価格による検証 | 製品価格は上昇しているか？ | 業界価格、アナリストレポートを検索 |
| 生産能力による検証 | 生産能力は本当に逼迫しているか？ | 納期データ、顧客からの不満を検索 |
| 資本による検証 | 増産のための設備投資はあるか？ | 企業の設備投資ガイダンスを検索 |

### 5.2 反証（マンガー流の否定）

| 反対方向の問い | 意味 |
|---------|------|
| 賢い投資家がこの株式を買わないのはなぜか？ | 既知の弱気材料を探す |
| このボトルネックは迂回できるか？ 代替ルートはあるか？ | 技術経路リスク |
| 中国／その他の企業は生産能力をすぐに複製できるか？ | 供給ショックのリスク |
| 最終需要が50%減速した場合、この企業はどうなるか？ | 下方感応度 |
| 経営陣は過去に高値圏で増資し、株式を希薄化させたことがあるか？ | 経営陣の信頼性 |
| 現在のバリュエーションには、どのような成長仮定が織り込まれているか？ | バリュエーションの妥当性 |

### 5.3 シグナルのクロスチェック

- 同一のボトルネックに関わる複数企業の株価が、いずれも上昇しているか？（業界による検証）
- 下流の顧客が決算で供給逼迫に言及しているか？（顧客による検証）
- 業界団体／調査機関に関連データがあるか？（第三者による検証）

## ステップ6：出力――ボトルネック機会ダッシュボード

### 6.1 ボトルネック機会ランキング表

| 順位 | 企業 | コード | 時価総額 | 年間売上高 | PSR | PER | ボトルネック工程 | ボトルネック評価 | 市場シェア | 売上高成長率 | シグナル強度 | バリュエーション判断 |
|------|------|------|------|--------|-----|-----|---------|---------|---------|---------|---------|---------|
| 1 | | | | | x | x | | S/A | | | ★1～5 | 妥当／割高／先行しすぎ |

**必須項目**：時価総額、年間売上高、PSR、PERは必須とし、「要確認」で省略してはならない。財務データを取得できない場合、シグナル強度は★★を上限とする。

シグナル強度の評価（バリュエーション確認の結果が評価に直接影響する）：
- ★★★★★ 複数のクロスチェック済み、顧客が採用済み、売上高に反映済み、バリュエーションは青信号（妥当なPSR + 黒字または黒字化目前）
- ★★★★ 大半の検証を通過、バリュエーションは青信号または黄信号（説明が必要）
- ★★★ 投資ロジックは成立しているが一部は要検証、バリュエーションの黄信号は許容可能（高成長のアーリーステージ企業など）
- ★★ 初期シグナル、またはボトルネックの投資ロジックは成立しているがバリュエーションが赤信号（時価総額 > TAMの20%、PSR > 30倍かつ成長率不足、時価総額が5年後予測を大幅に上回るなど）
- ★ 概念のみで未検証

### 6.3 推奨アクション

| 投資候補 | 推奨アクション | 理由 |
|------|---------|------|
| A | `/investment-team` で詳細調査を実行 | S級ボトルネック + 複数の検証 |
| B | ウォッチリストに追加し、次四半期の決算を待つ | 投資ロジックは成立しているが、売上高に未反映 |
| C | 現時点では追跡しない | 代替技術リスクが高すぎる |

## 1時間ごとのスキャンモード（定期タスク用）

1時間に1回実行し、「有益な情報がある場合のみレポートを作成する」方式を採用する。

### スキャン手順（1時間ごと）

1. **ニューススキャン**：過去1～2時間のサプライチェーン関連ニュースを検索
   - キーワード：supply chain bottleneck, shortage, capacity constraint, allocation, lead time, sole source, ボトルネック, 品不足, 生産能力, 値上げ
   - 対象：英語 + 中国語の情報源
2. **市場シグナル**：追跡中の企業の株価変動を確認（特に5%超の異常変動に注目）
3. **決算／開示**：ボトルネック関連企業が決算または重要な開示を発表していないか確認
4. **バリュエーション機会**：ウォッチリストの企業が、市場全体の下落などにより買い場に入っていないか確認
5. **レポート作成の要否を判断**：
   - 新たなボトルネックのシグナル、明確な投資候補、重大な状態変化がある → **レポートを作成**
   - 新たな発見がない → **レポートを作成しない**。ログに「今回は新規シグナルなし」とのみ記録

**1日1フォルダ**：`reports/bottleneck-map/YYYY-MM-DD/`

## AI調査におけるバイアスの自覚

| バイアス | 現れ方 | 対応策 |
|------|-----|------|
| 業界大手への偏り | 検索結果が大型株で占められる | 小型株のサプライヤーを意図的に検索し、`small cap` のキーワードを追加 |
| 英語への偏り | 日本・韓国・台湾企業を見落とす | 日本・韓国・台湾市場のサプライヤーを必ず検索 |
| 物語への偏り | 「AI関連」というラベルに引き付けられる | 市場のラベルではなく、実際のサプライチェーン上の位置だけを見る |
| 確証バイアス | ボトルネック発見後、肯定的な根拠だけを探す | 反証（ステップ5）を強制的に実施 |
| 鮮度バイアス | 古い情報に依存する | 直近30日間のデータを優先して検索 |

## 中核原則（最優先）

1. **AIに株式を推奨させず、AIにサプライチェーンを分解させる** — 答えより問いが重要
2. **物理を優先** — 実際の物理的な製品／材料／装置を必要とする工程だけに注目
3. **第2層、第3層** — すでに十分織り込まれている業界大手を追わない
4. **クロスチェック** — 各結論について、少なくとも2つの独立した情報源を確認
5. **不確実性に正直に向き合う** — データが見つからなければ「データ不足」と記載し、推測で補完しない
6. **ボトルネックには時間的制約がある** — すべてのボトルネックはいずれ解消される。重要なのは時間枠の判断
7. **小型株 ≠ 良い機会** — 小型株でも質の低い企業はある。財務の質に関する基準を必ず通過させる
8. **ボトルネックが実在すること ≠ 投資機会であること** — 企業が最も深刻なボトルネックを押さえていても、PSRが30倍を超えるか、なお赤字であれば、現在の価格は買い場ではない。**バリュエーションは絶対的な基準であり、ボトルネック事業の純度、シグナル強度、ストーリーの魅力で覆してはならない。** ボトルネック銘柄の上昇を1つ逃すほうが、PSR 100倍で赤字企業を買うよりよい
9. **CLAUDE.mdの客観性原則に従う** — 強気を前提とせず、データを先に、結論を後にする

## 出力要件

1. **レポートの保存場所**：
   - 完全スキャン：`reports/bottleneck-map/{トレンド名}-bottleneck-{YYYYMMDD}.md`
   - 日次スキャン：`reports/bottleneck-map/daily/{YYYY-MM-DD}-{am/pm}.md`

6. **両面を示す**：各中核判断に反対方向の論拠を添える
