# 日本株ポートフォリオ・レビュー

`$ARGUMENTS` の保有一覧を、個別企業の良否ではなく組合全体の観点から見直す。

## 入力

- `7203 30%, 7974 20%, 現金50%`
- `7203 500株 @2800円, ...`
- `私の保有`（`reports/portfolio-latest.md` がある場合）

提供された数量、取得価額、比率だけを使う。機密なら比率分析に限定し、口座残高や個人情報を推測しない。対象は東証内国普通株と円現金に限定する。

---

## 第1段階：保有を標準化する

| 会社 | コード | 株数 | 取得価額 | 現在値 | 時価 | 比率 | 損益 |
|---|---|---:|---:|---:|---:|---:|---:|

比率のみなら金額欄は空欄とする。`reports/portfolio-latest.md` があれば読み、今回入力と食い違う場合は利用者の最新入力を優先し差分を示す。

---

## 第2段階：最新データを並行取得する

各保有について、利用可能なら独立Agentで次を並行収集する。

1. 株価、PER、PBR、配当利回り。
2. 最新決算の重要変化。
3. 直近の適時開示、M&A、経営・統治イベント。
4. 会社予想と市場が織り込む成長。
5. 投資仮説の撤回条件に触れた事実。

Agentが使えない場合は順番に実行する。各保有に情報充実度A/B/Cを付け、Cの結論は低信頼とする。

```bash
python tools/jpstock_data.py quote {証券コード}
python tools/financial_rigor.py --locale ja verify-valuation --price {株価} --eps {EPS} --bvps {BPS} --dividend {配当}
```

データは `skills/financial-data-jp.md` に従う。

---

## 第3段階：個別保有の健康診断

| 会社 | 現在評価 | 元の仮説 | 健康度 | 現在比率 | 仮判断 |
|---|---|---|---:|---:|---|

各社について答える。

- 今日保有していなければ、現在価格で新規に検討するか。
- 明日から5年間取引できなくても保有できるか。
- 元の仮説は維持、弱化、破綻のどれか。
- 現在比率は企業確信度と損失耐性に整合するか。
- 親子上場、政策保有株、支配株主、少数株主保護に新しい問題はないか。

株価下落だけで仮説破綻とせず、上昇だけで仮説強化としない。

---

## 第4段階：組合全体

### 4.1 集中

| 指標 | 現在値 | 参考帯 | 判断 |
|---|---:|---:|---|
| 最大保有比率 | | 参考として40%未満 | |
| 上位3社比率 | | 50～80% | |
| 保有社数 | | 5～15社 | |
| 現金比率 | | 状況依存 | |

参考帯は規則ではない。高集中には深い理解、財務耐性、退出可能性が必要で、低集中でも同じ利益要因に偏れば分散ではない。

### 4.2 共通リスクと相関

| 保有A | 保有B | 共通要因 | 同時悪化の経路 | 重要度 |
|---|---|---|---|---|

業種、顧客、設備投資、金利、為替、資源価格、国内消費、輸出需要、災害、電力、規制、親会社・取引系列を確認する。

- 50%超が同じテーマまたは需要要因に依存しないか。
- 表面上の業種が違っても同じ顧客設備投資へ依存しないか。
- 円高・円安、金利上昇、国内景気後退に何割が同方向か。
- ガバナンス上の共通弱点がないか。

### 4.3 機会費用

同じ期間と同じ仮定で各保有の円建て期待収益範囲を比較する。

| 順位 | 会社 | 比率 | 期待収益範囲 | 確信度 | 主な下方要因 |
|---:|---|---:|---:|---|---|

```bash
python tools/financial_rigor.py --locale ja three-scenario --price {株価} --eps {EPS} --shares {株式数_億株} --growth {楽観} {基準} {保守} --pe {楽観PER} {基準PER} {保守PER} --currency JPY
```

FCF利回り＋利益成長を入口にできるが、倍率変化、希薄化、配当を二重計上しない。最下位保有が調査日時点の円無リスク資産より劣る場合、現金または上位候補との入替条件を検討する。無リスク金利は当日の公表値を使い、固定値を埋め込まない。

### 4.4 ストレステスト

| シナリオ | 仮定 | 影響が大きい保有 | 組合への範囲 | 耐えられるか |
|---|---|---|---:|---|
| 国内景気後退 | 利益20～30%減 | | | |
| 円急変 | 会社開示の感応度 | | | |
| 金利上昇 | 借換費用・倍率低下 | | | |
| 設備投資循環の反転 | 受注・価格低下 | | | |
| 大規模災害・供給停止 | 主要拠点停止 | | | |

各社の業種と過去変動に基づく範囲を示し、見せかけの一点精度を避ける。二重計上した共通ショックがないか確認する。

## 第5段階：最適化候補

### 5.1 調整表

| 判断 | 会社 | 現在比率 | 検討比率 | 条件と理由 |
|---|---|---:|---:|---|
| 追加 | | | | |
| 維持 | | | | |
| 縮小 | | | | |
| 売却候補 | | | | |
| 監視 | | | | |

売買命令ではなく、情報と条件に基づく検討案として示す。税、流動性、生活資金、リスク許容度が不明なら比率を断定しない。

### 5.2 代替候補

現金以下の保有や過大現金がある場合も、本スキル内で未調査銘柄を推薦しない。`skills/industry-research-jp.md` または `skills/investment-checklist-jp.md` で候補を別途検証する。

### 5.3 現金

| 現在現金比率 | 検討範囲 | 根拠 | 使う条件 |
|---:|---:|---|---|

現金を失敗と決めつけず、任意性と機会費用を比較する。

## 第6段階：報告

```text
1. 組合概要
2. 個別保有の健康診断
3. 集中と実質的な共通リスク
4. 機会費用順位
5. ストレステスト
6. 調整候補と条件
7. 現金管理
8. 次回確認日と観測事項
```

結論は必ず答える。

1. 全体健康度：優良／良好／要調整／重大問題。
2. 最も重要な一つの行動条件。
3. 最大の共通リスク。

---

## 第7段階：保存と監査

`reports/portfolio-latest.md` に、最新保有表、基準日、結論、調整履歴、次回確認日を保存する。既存ファイルがある場合は履歴を消さず、変更前スナップショットを残す。

```bash
python tools/report_audit.py --locale ja extract --report reports/portfolio-latest.md --market jp
python tools/report_audit.py --locale ja verdict --results '<照合済みJSON>' --report portfolio-latest.md --market jp
```

監査不合格なら数値を直して再実行する。個別の良い企業も過大比率なら組合を損ねる。四半期を基本に見直し、事実変化のない日々の価格で過剰売買しない。
