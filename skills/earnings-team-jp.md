# 決算精読チーム：4人の達人による並列分析 + WeChat公式アカウントでの公開

`$ARGUMENTS` の決算をチームで精読・分析する。4人の達人が並列で決算を読み解き、編集者が記事として磨き上げ、読者レビューで品質を確認し、最終的にそのまま公開できるWeChat公式アカウント向け記事を作成する。

**対応する入力形式**：`企業名 四半期`。例：`テンセント 2025Q4`、`PDD 2025年次報告書`、`美団 最新`

## 設計思想

優れた決算分析は、2つの問題を解決する必要がある：
1. **自分が将来を理解できること**――異なる4つの視点による詳細調査が必要
2. **読者が価値を理解できること**――編集による推敲と、読者視点での品質確認が必要

このSkillのプロセスは3つのフェーズに分かれる：
- **フェーズ1・調査**：4人の達人が並列で決算を精読（段永平は事業の本質、ウォーレン・バフェットは財務の質、チャーリー・マンガーは競争環境の変化、李録はリスクシグナルを見る）
- **フェーズ2・統合**：Team Leadが4つの視点を統合し、調査レポートの初稿を作成
- **フェーズ3・公開**：編集AgentがWeChat公式アカウント向け記事に書き換え + 読者レビューAgentが修正意見を提示 → Team Leadが最終稿を作成

---

## フェーズ1：4人の達人による並列調査

### ステップ1：一次資料を取得する

AgentツールでバックグラウンドAgentを起動し、以下の原資料を**並列**で取得する：

| 資料の種類 | 取得元 | 優先度 |
|---------|---------|--------|
| 決算原文 | 企業のIRページ、SEC EDGAR（米国株）、HKEXnews（香港株）、CNINFO（中国A株） | 最高 |
| 決算説明会の議事録 | Seeking Alpha、企業のIRページ、雪球 | 最高 |
| 経営陣から株主への書簡 | 年次報告書から抽出 | 高（年次報告書の場合のみ） |
| 前回の決算／決算説明会 | 同上 | 高（公約の追跡に使用） |

**資料の入手可能性評価**：

| 評価 | 特徴 | 影響 |
|------|------|------|
| A級 | 全文の原文を入手 | 全ステップを通常どおり実行 |
| B級 | 原文の一部または第三者の集計のみ入手 | 「一次資料ではない」と明記し、注記分析の比重を下げる |
| C級 | 報道とデータサイトの要約のみ | 中核データの変化に集中し、注記の深掘りは省略。「一次資料不足」と明記 |

資料の入手可能性評価を各Agentに伝え、分析の深度に反映させる。

### ステップ2：チームの枠組みをユーザーに提示する

| フェーズ | 役割 | 達人／位置付け | 中核タスク |
|------|------|----------|---------|
| 調査 | **Team Lead**（あなた自身） | 全体調整 | 統括、統合、最終稿作成 |
| 調査 | 事業の本質を読む担当 | 段永平 | この事業は良くなったか、悪くなったか？ |
| 調査 | 財務品質の監査担当 | ウォーレン・バフェット | 稼いでいるのは本物の現金か、見せかけの利益か？ |
| 調査 | 競争環境の変化を読む担当 | チャーリー・マンガー | 競争環境はどう変わっているか？ |
| 調査 | リスクシグナルの発掘担当 | 李録 | 経営陣は何を隠しているか？ |
| 公開 | 編集 | WeChat公式アカウント向け執筆 | 調査レポートを優れた記事に書き換える |
| 公開 | 読者レビュー | 一般投資家 | 読者が理解できるか？ 有益か？ |

### ステップ3：4つの並列調査Agentを起動する

Agentツールを使用し、**同一メッセージ内**で4つのバックグラウンドAgentを起動する。

---

#### Agent 1：事業の本質を読み解く（段永平の視点）

**中核となる問い：この決算が示す事業の本質は、良くなったか、悪くなったか？**

> 段永平：「投資とは1つの事業を買うこと。決算を見るのは数字を見るためではなく、その事業が変わったかを見るためだ。」

分析内容：

1. **売上高構成の分解と解釈**
   - 事業別／地域別の売上高。どこが加速し、どこが減速しているか
   - 数字を並べるだけではなく、各事業セグメントがどのようなビジネスロジックを示しているか
   - 売上高の成長は「数量」か「価格」か？ どちらがより健全か？

2. **ユーザー／顧客価値の変化**
   - DAU／MAU／有料ユーザーなどの運営指標の変化
   - 利用時間、ARPU、継続率などの質的指標
   - プラットフォーム／製品がユーザーに提供する価値は強まっているか、弱まっているか？

3. **経済的な堀の検証**
   - 粗利率の変化から、価格決定力が安定しているかを見る
   - 市場シェアの変化から、競争障壁が有効かを見る
   - 顧客のスイッチングコスト／ネットワーク効果が弱まっているシグナルはないか

4. **「優れた事業」の基準による評価**
   - 段永平の3条件：差別化、価格決定力、持続可能な競争優位性――当期の変化
   - 事業は「重く」なっているか、「軽く」なっているか？
   - 仮に明日この企業がなくなったら、ユーザーは非常に困るか？ 今回の決算でその答えは変わったか？

5. **経営陣のプロダクト感覚**
   - 経営陣が製品／ユーザーについて語る際、具体的な言葉を使っているか、官僚的な言葉を使っているか
   - 印象的な製品洞察、または懸念すべき現場との乖離を示すシグナルはあるか

**出力要件**：各小項目に 🟢改善 / 🟡横ばい / 🔴悪化 を付け、段永平流の総括コメントを示す。

---

#### Agent 2：財務品質の監査（ウォーレン・バフェットの視点）

**中核となる問い：この企業が稼いでいるのは本物の現金か、見せかけの利益か？ 安全余裕は変わったか？**

> ウォーレン・バフェット：「決算を見るとき、私が最初に開くのはキャッシュフロー計算書だ。」

分析内容：

1. **中核となる財務データの抽出と検証**
   - 売上高、売上総利益、営業利益、純利益――GAAPとNon-GAAPの両方
   - GAAP vs Non-GAAPの差：差額はいくらか、どこで生じたか、差は拡大しているか縮小しているか
   - 重要データは2つ以上の情報源でクロスチェック

   ```bash
   python3 tools/financial_rigor.py cross-validate \
     --metric "revenue" --values {値1} {値2} --sources "情報源1" "情報源2"
   ```

2. **キャッシュフロー分析（最重要）**
   - 営業キャッシュフローと純利益の比率（100%超が望ましく、80%未満は要警戒）
   - フリーキャッシュフロー = 営業キャッシュフロー - 設備投資
   - 設備投資の内訳：維持投資 vs 成長投資
   - 自社株買いと配当の金額

3. **利益の質の検証**
   - 売掛金の成長率 vs 売上高成長率
   - 棚卸資産の成長率 vs 売上高成長率
   - 営業キャッシュフローと純利益の差の傾向
   - 資産計上される支出が突然増えていないか
   - 非経常利益の比率

4. **バランスシートの健全性**
   - ネットキャッシュ／純負債の変化
   - 売掛金／棚卸資産の回転日数の変化
   - のれんおよび無形資産の減損リスク

5. **バリュエーションと安全余裕の更新**

   ```bash
   python3 tools/financial_rigor.py verify-market-cap \
     --price {価格} --shares {発行済株式数} --reported {レポート記載の時価総額} --currency {通貨}
   python3 tools/financial_rigor.py verify-valuation \
     --price {価格} --eps {EPS} --bvps {1株当たり純資産}
   python3 tools/financial_rigor.py three-scenario \
     --price {価格} --eps {EPS} --shares {発行済株式数・億株} \
     --growth {強気} {中立} {弱気} --pe {強気PER} {中立PER} {弱気PER}
   ```

**出力要件**：すべての計算にツールの出力記録を添付し、利益の質を 🟢／🟡／🔴 で示し、ウォーレン・バフェット流の総括コメントを付ける。

#### Agent 3：競争環境を読み解く（チャーリー・マンガーの視点）

**中核となる問い：この決算は、競争環境のどのような変化を明らかにしたか？**

> チャーリー・マンガー：「私は、自分がどこで死ぬかを知りたい。そうすれば、そこへ行かずに済むからだ。」

分析内容：

1. **決算データから競争の変化を推定**
   - 売上高成長率 vs 業界成長率――上回ったか、下回ったか？
   - 粗利率の変化が、競争の激化／緩和を示しているか
   - マーケティング費用率の変化――顧客獲得により多くの資金が必要になったか？
   - 研究開発投資――能動的な投資か、追随を余儀なくされたものか？

2. **同時期の競合との比較**
   - 主要競合の同時期の重要指標と比較（公開済みの場合）
   - 成長率、利益率、投資規模を比較
   - 誰が勝ち、誰が負けているか？

3. **競争に関する経営陣の説明**
   - 決算説明会で競争環境をどのように説明しているか
   - 競合を名指ししているか？ 語調は自信に満ちているか、不安を示しているか？
   - 新たな競争上の脅威はあるか？

4. **業界トレンドのシグナル**
   - 技術変化（AI／新たなプラットフォームなど）の影響
   - 規制変更が競争環境に与える影響
   - 消費／需要側のトレンド

5. **チャーリー・マンガー流の逆向き思考**
   - 何がこの企業を死に追いやるか？ 当期の決算に、その脅威を示すシグナルはあるか？
   - 5年後に振り返ったとき、この決算は「転換点」になっているか？

**出力要件**：競争環境の判断（改善／横ばい／悪化）、競合比較表、チャーリー・マンガー流の逆向きコメントを示す。

---

#### Agent 4：リスクシグナルの発掘（李録の視点）

**中核となる問い：経営陣はこの決算で何を隠しているか？ どのシグナルが点滅しているか？**

> 李録：「投資で最も重要なのは、資本の永久的な損失を避けることだ。」

分析内容：

1. **経営陣の語調分析**
   - 経営陣による説明と決算説明会の発言を段落ごとに読み、シグナルを付ける：
   - 🟢率直さのシグナル（問題を自ら認める）/ 🟢明確さのシグナル（定量目標がある）
   - 🔴曖昧さのシグナル（空疎な言葉）/ 🔴論点転換のシグナル（質問に答えない）/ 🔴外部要因への責任転嫁

2. **公約の追跡**
   - 前回の経営陣による具体的な公約 vs 当期の実際の達成状況を、項目ごとに比較
   - 段永平：「経営陣が信頼できるかを見るには、以前言ったことを実行できたかを見ればよい。」

3. **注記と隠れた情報**
   - 関連当事者取引、株式報酬による希薄化、偶発負債
   - 会計方針の変更、セグメント別利益率の差
   - 顧客／サプライヤー集中度の変化

4. **決算説明会Q&Aから厳選**
   - 最も鋭い3～5件のアナリスト質問と、経営陣の回答品質の評価

5. **資本の永久的損失リスク**
   - 永久的な損失につながり得るシグナルが出ていないか
   - 規制／コンプライアンス／訴訟リスクの新たな進展
   - 経営陣が不可逆的な誤った意思決定をしていないか

**出力要件**：経営陣の信頼度を★1～5で評価し、公約達成率、リスクシグナル一覧、李録流の総括コメントを示す。

## フェーズ2：Team Leadによる調査レポートの統合

4件の調査レポートがすべて揃った後、Team Leadが統合して調査レポートの初稿を作成する。

**統合の要点**――レポートをつなぎ合わせるのではなく、交差点と矛盾点を探す：

1. **4つの視点の共通認識**：4人の達人全員が同意する結論は、最も信頼度が高い
2. **4つの視点の矛盾**：例えば、段永平は事業が良くなったと言う一方、チャーリー・マンガーは競争が悪化していると言う――このような矛盾こそ最も価値のある分析
3. **見落とされた領域**：4人全員が重視しなかったものが、実は最も重要ではないか？

#### 調査レポートの構成

```markdown
# {企業名} {期間} 決算精読レポート
**4人の達人による並列分析 | {日付}**

## 1. 一文での結論
> 50～100字：予想を上回る／予想どおり／予想を下回る、中核的な変化、投資仮説への影響。

## 2. 当期で最も重要な3つの変化
本当に重要な変化に絞り、データを羅列しない。各項目100字以内。

## 3. 4人の達人による評価表
| 視点 | 達人 | 中核となる問い | 結論 | 評価 | 前期比 |
|------|------|---------|------|------|--------|

## 4. 主要データ一覧
重要な財務・運営指標の表（当期 vs 前期 vs 前年同期比）

## 5. 各視点からの詳細分析
各視点で最も重要な発見を3～5項目

## 6. 経営陣の語調と公約の追跡
公約達成表 + 語調の変化の分析

## 7. 4人の達人ならどうするか？
| 達人 | 保有している場合 | 保有していない場合 | 理由 |

## 8. 結論
1. 予想を上回る／予想どおり／予想を下回る？
2. 投資仮説への影響：強化／影響なし／弱化／崩壊
3. 次のカタリスト
4. 売買・保有に関する提案
```

## フェーズ3：編集・推敲 + 読者レビュー

調査レポートの完成後、2つのAgentを**並列**で起動する：

### Agent 5：編集（WeChat公式アカウント向け記事への書き換え）

**位置付け**：本格的な調査レポートを、WeChat公式アカウントの読者が読みたくなり、理解できる記事へ書き換える。

**中核原則**：
- 重要なデータと結論をすべて保持し、専門的な深度を下げない
- 表現を改善し、専門家ではない投資家も投資ロジックを追えるようにする
- 「入門解説」にするのではなく、「専門的な内容を疲れずに読めるようにする」

**具体的なタスク**：

1. **タイトルと冒頭**
   - タイトルは情報量があり、クリックしたくなるものにするが、煽り見出しにはしない
   - 良いタイトルの例：「快手は260億元をAIに賭けた。その賭けは成功したか？」
   - 悪いタイトルの例：「衝撃！快手の決算が大暴落！」
   - 冒頭100字以内で明確にする：この決算で最も重要な結論は何か、なぜ読者が注目すべきか

2. **構成の最適化**
   - 調査レポートは自分のために読むもの、WeChat公式アカウントの記事は他者に読んでもらうもの――投資ロジックの順序を調整する
   - 「最も重要な3つの変化」を最初に置く（逆ピラミッド構造）
   - 表は残しつつ簡潔にし、長い分析は要点形式に変更
   - 約500字ごとに「ここまでの要約」を入れ、読者の理解を助ける

3. **表現の推敲**
   - 硬い財務用語を、たとえ／場面で説明する：「営業キャッシュフローが純利益を30%下回る」→「100元を稼いだはずなのに、ポケットには70元しか入っていない」
   - 4人の達人によるコメントは記事の核――すべて鋭く、記憶に残る表現にする
   - 1段落は4行以内、1文は30字以内
   - 対比とコントラストを適度に使い、読み進めやすいリズムを作る

4. **読者価値の検証**
   - 各セクションで自問する：読者はこの段落を読んだ後、どのような意思決定ができるか？ 答えが「何もできない」なら、書き換えるか削除する
   - 記事末尾に明確な「では、どうするか？」を置き、保有者と様子見の読者に分けて行動指針を示す

5. **形式の最適化**
   - WeChat公式アカウントで読みやすいレイアウト：短い段落、明確な小見出し、簡潔な表
   - 適切な区切り線と引用形式を加える
   - 記事の長さは1,000～3,000字に収める（長すぎると読者が離脱する）

**出力**：書き換え後のWeChat公式アカウント向け記事全文。

---

### Agent 6：読者レビュー（一般投資家の視点）

**位置付け**：「バリュー投資に関心があり、財務の基礎知識を持ち、当該企業を保有または注目している」一般投資家として記事をレビューする。

**レビュー項目**：

1. **読みやすさ（比重30%）**
   - 全文を読むのに何分かかるか？ 読み飛ばしたくなる段落はあるか？
   - 理解できない、または繰り返し読む必要がある箇所はどこか？
   - リズムはどうか？ 「読むのに疲れた」と感じないか？

2. **情報価値（比重30%）**
   - 読後、この企業への理解は深まったか？
   - 「なるほど、そういうことか」と感じる瞬間はあったか？
   - 他で見た分析と比べ、この記事の独自性は何か？
   - 不要な情報、削除しても理解に影響しない情報はどれか？

3. **信頼性（比重20%）**
   - データに情報源があるか？ 重要な判断に根拠があるか？
   - 賛否両面を示しているか？ 強気または弱気の一方に偏っていないか？
   - 「自信過剰ではないか」と不快に感じる判断はないか？
   - 4人の達人からの引用は適切で、説得力があるか？

4. **行動への有用性（比重20%）**
   - 読後、どう行動すべきか分かるか？
   - 「保有者」と「様子見の読者」への提案は十分具体的か？
   - 次に何へ注目すべきか？（カタリスト、時期）

## 既存Skillとの関係

| Skill | 位置付け | 使用する場面 |
|-------|------|--------|
| `/earnings-review` | 単一Agentによる決算精読 | 迅速に確認し、1つの視点だけで十分な場合 |
| **`/earnings-team`（本Skill）** | **6つのAgentによるチーム精読 + WeChat公式アカウントでの公開** | **重要企業の重要な決算で、深度と公開の両方が必要な場合** |
| `/investment-team` | 4つのAgentによる包括的な企業調査 | 企業を初めて調査する場合 |

## 重要原則

- **要約ではなく原文を読む**：あらゆる手段を尽くして一次資料を取得する
- **4つの視点は4つの部門ではない**：相互に検証し、異議を唱え合う。別々の意見を並べるだけではない
- **Team Leadの価値は総合判断にある**：共通点と矛盾点を探す。レポートをつなぎ合わせるだけではない
- **結論を明確にする**：「全体としておおむね予想どおりだが、注目すべき点もいくつかある」は認めない
- **反対方向の検証を全プロセスで行う**：肯定的な発見には、必ず反対方向の論拠を添える
- **編集は専門性を下げることではない**：専門的な内容を読みやすくすることであり、入門解説に変えることではない
- **読者レビューを形式的に済ませない**：実際に読者の立場から問題点を指摘する
- **データの正確性**：重要データをクロスチェックし、`financial_rigor.py` ツールで再計算する
