# 日本株の業界ファネル：全母集団から最大3社へ

## 適用場面

業界、指数、テーマから調査候補を絞るときに使う。既に一社が決まっている場合は個別調査スキルを使う。

## ファネル全体

```text
東証内国普通株の母集団
→ 事業適合・流動性・財務の粗選別
→ 最大10社の詳細分析
→ 4視点の深掘り
→ 最大3社と見送り条件
```

## ステップ1：母集団を作る

### 1.1 対象

JPX上場会社情報、業種分類、会社IRを使い、東証プライム・スタンダード・グロースの内国普通株を列挙する。ETF、REIT、外国株、対象事業の構成比が小さい企業を分ける。

### 1.2 入力別の探索

- 業界：売上構成から主要企業を15〜30社確認する。
- 指数：構成銘柄の完全な一覧から開始する。
- テーマ：需要との因果が確認できる企業だけを含める。

### 1.3 母集団表

| 会社 | コード | 市場 | 対象事業比率 | 時価総額 | 売買代金 | 採否 |
|---|---|---|---:|---:|---:|---|

除外会社も理由を残す。

## ステップ2：5つの粗選別基準で最大10社へ

1. 対象事業が利益へ十分に寄与している。
2. 継続企業、過大債務、重大な会計・誠実性問題がない。
3. 利益と営業CFが長期で大きく乖離していない。
4. 競争優位または改善経路を説明できる。
5. 株式数と円建て評価を確認できる。

| 会社 | 事業適合 | 財務 | CF | 優位性 | 評価可能性 | 結果 |
|---|---|---|---|---|---|---|

情報不足は自動的な不合格ではなく「保留」とする。

## ステップ3：最大10社を詳細分析する

各社300〜500字を目安に次を同じ形式で記載する。

### `{会社名}（{証券コード}）`

- 一文事業モデル。
- 対象事業の売上・利益比率。
- 3〜5年の売上、利益、営業CF、ROE、ROIC、株式数。
- 価格決定力と競争優位。
- 設備投資、負債、景気循環。
- 政策保有株、親子上場、支配株主、少数株主保護。
- 現在評価と過去・国内同業比較。
- 深掘りすべき論点と除外条件。

```bash
python tools/financial_rigor.py --locale ja verify-valuation --price {株価} --eps {EPS} --bvps {BPS}
python tools/financial_rigor.py --locale ja verify-market-cap --price {株価} --shares {株式数} --reported {時価総額} --currency JPY
```

## ステップ4：4視点で最終候補を比較する

### 4.1 事業の本質

顧客価値、反復性、価格決定力、再投資必要額。

### 4.2 競争優位

ブランド、切替費用、規模、コスト、技術、認証、希少資産。

### 4.3 逆向き思考

失敗経路、循環ピーク、技術代替、顧客内製化、規制、会計上の赤旗。

### 4.4 長期構造と経営

業界成長を価値へ変える能力、資本配分、ガバナンス、撤回条件。

### 4.5 総合推奨度

| 会社 | 事業 | 優位性 | 財務 | 経営 | 評価 | 情報品質 | 総合 |
|---|---:|---:|---:|---:|---:|---:|---:|

点数だけで選ばず、異なる失敗経路と価値獲得源を持つ最大3社を選ぶ。適格企業がなければ0社で終了する。

## ステップ5：総合出力

### 5.1 最終候補表

| 役割 | 会社 | 中核論点 | 現在評価 | 買付条件 | 撤回条件 |
|---|---|---|---|---|---|

### 5.2 業界位置

需要、供給、在庫、設備投資、価格、利益率から導入・成長・過熱・調整・成熟のどこかを判定する。

### 5.3 情報充実度

大型・有名企業に偏っていないか、ナラティブを証拠より優先していないか、未上場企業の存在を業界構造から落としていないかを確認する。

### 5.4 更新項目

未取得データ、次の決算、統計、規制、設備稼働等を期日付きで示す。

## 出力・監査

`reports/{業界}/{業界}-industry-funnel-{YYYYMMDD}.md` に保存する。

```bash
python tools/report_audit.py --locale ja extract --market jp --report {レポート}
python tools/report_audit.py --locale ja verdict --market jp --results '<照合済みJSON>' --report {レポート名}
```

すべての採用・除外理由を追跡可能にし、監査不合格なら公開版としない。
