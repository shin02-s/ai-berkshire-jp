# 業界ファネル・スクリーニング：市場全体から3社へ絞り込むバリュー投資選定プロセス

`$ARGUMENTS` の業界／テーマについてファネル型のバリュー投資スクリーニングを実行し、市場全体のスキャンから段階的に3社の最終投資候補まで絞り込む。

## 使用する場面

業界または投資テーマ（「AIコンピューティング」、「革新的医薬品」、「ロボット」など）を指定し、次を実現したい場合：
1. 重要な投資候補を漏らさない（中国A株、香港株、米国株、未上場候補を含む）
2. 統一基準で「ストーリーだけの銘柄」と質の不十分な企業を除外する
3. 本当に詳細調査に値する上位3社へリソースを集中する
4. 各段階に明確な採用／除外基準を設け、後から検証・追跡できるようにする

`industry-research` との違い：
- `industry-research` は産業チェーンの構造と全体像、工程別の断面分析に重点を置く
- `industry-funnel` は個別銘柄の選定ファネルに重点を置き、市場全体から段階的に3社へ絞り込む

両者は相互補完できる。まず `industry-research` で産業チェーンの構造を把握し、次に `industry-funnel` で投資候補を選別する。

---

## ファネル構造の全体像

```
第1層：市場全体のスキャン   30～60社（売買活発度 + 上昇率 + 時価総額上位30社の和集合）
        ↓ バリュー投資の5つの必須指標
第2層：一次選別             10社以下（5項目すべて合格 + 経済的な堀が★★★以上）
        ↓ 詳細分析
第3層：詳細分析             10社以下（1社300～500字の構造化分析）
        ↓ 最終選定
第4層：4人の達人による深掘り  3社（1社800～1,200字、ウォーレン・バフェット／チャーリー・マンガー／段永平／李録の4視点）
        ↓
出力：投資提案 + 売買シグナル + ポジションサイズの提案
```

各層で「除外した投資候補」について、除外理由を必ず残す。ブラックボックス化してはならない。

## ステップ1：市場全体のスキャン入口

### 1.1 活発な銘柄の定義（3分類の和集合）

**A類 - 売買活発度**：
- 直近30日間の1日平均売買代金が業界上位（中国A株／香港株／米国株でそれぞれ上位30社）

**B類 - 上昇率ランキング**：
- 直近30日間の上昇率上位20社
- 直近90日間の上昇率上位20社
- 両者の和集合

**C類 - 時価総額によるアンカー**：
- 業界内の時価総額上位30社（株価の上昇・下落を問わない）

最終スキャン対象 = A ∪ B ∪ C。想定30～60社。

### 1.2 必ず検索する市場

| 市場 | 推奨情報源 |
|------|---------|
| 中国A株（上海・深圳） | 同花順／Eastmoneyの業界セクター、通達信 |
| 香港株 | Futu／同花順香港株、HKEXの業種分類 |
| 米国株 | NASDAQ／NYSEの業界ETF構成銘柄、Yahoo Finance |
| 国際市場 | 日本・韓国・台湾・欧州の関連企業を漏らさない（特に半導体、電子） |
| 未上場企業 | 「将来のIPO候補」セクションを別に設け、最新のバリュエーションと想定IPO時期を明記 |

### 1.3 出力形式

| 企業名 | コード | 市場 | 時価総額 | 本業を一文で | 当該業界の比率 | 選定区分（A/B/C） |
|-------|------|-----|------|----------|-----------|----------------|

**重要な自己点検**：
- 当該業界の比率が30%未満の「関連しているだけの銘柄」は慎重に扱い、「純粋な投資候補ではない」と明記
- 英語資料が少ないことを理由に、中国／アジア市場を漏らさない
- AIが業界大手を好むことを理由に、小型株を漏らさない

## ステップ2：バリュー投資の5つの必須指標で一次選別 → 10社以下

ステップ1の30～60社に、5つの必須指標を1社ずつ適用する。

### 2.1 5つの必須指標

| # | 指標 | 合格基準 | 緩和条件 | データソース |
|---|------|---------|---------|---------|
| 1 | PERによるバリュエーション | 妥当（過去レンジ、同業他社と比較） | 高成長ならPEG 1.5未満まで緩和可能 | 決算 + Wind／同花順 |
| 2 | 自己資本利益率 | 15%超、または直近3年間で改善傾向 | 資本集約型業界は緩和可能 | 決算 |
| 3 | 営業キャッシュフロー | プラス、かつ純利益の70%超 | — | 決算 |
| 4 | 負債比率 | 60%未満 | 公益／電力は70%まで緩和可能 | 決算 |
| 5 | 経済的な堀の簡易評価 | ★★★以上 | — | 定性判断 |

**経済的な堀の5分類**：
- ブランド／価格決定力
- スイッチングコスト／ユーザーの定着性
- ネットワーク効果
- 規模の経済
- 技術／許認可／資源の参入障壁

### 2.2 出力形式

| 企業 | PER | 自己資本利益率 | キャッシュフロー／純利益 | 負債比率 | 経済的な堀 | 総合 | 採用／除外 | 除外理由 |
|------|----|----|-----------|-------|-------|------|------|---------|

**採用ルール**：
- 5項目すべて合格 → そのまま採用
- 4項目合格 + 1項目が合格に近い → 採用するが黄色で表示
- 合格が4項目未満 → 除外し、理由を明記

**目標**：採用は10社以下。採用が多すぎる場合（12社超）は、経済的な堀の基準を★★★★へ引き上げて再選別する。

## ステップ3：詳細分析（10社以下、1社300～500字）

一次選別を通過した企業について、1社ずつ構造化して分析する。

### 3.1 各社の分析テンプレート

```
## {企業名}（{コード}）

**ビジネスモデルを一文で**：
（何を、誰に売り、どのように料金を得るか）

**財務の質**：
- 売上高成長率 / 利益成長率 / 粗利率 / 自己資本利益率 / キャッシュフロー
- 重要な変化（直近1～2年間で最も重要な財務上の転換点）

**経済的な堀の深さ**：
- 主な経済的な堀の種類 + 具体的な根拠
- 5年後も経済的な堀が残るかについての簡潔な判断

**主なリスク（上位3項目）**：
1.
2.
3.

**バリュエーションの簡易評価**：
- 現在のPER／PSR／EV/EBITDA + 過去レンジ内の位置
- 同業他社との比較
- 一文での結論：割高 / 妥当 / 割安

**最終3社に選ぶか？**：はい / いいえ（理由）
```

### 3.2 最終3社の選定基準

スコア順に上位3社を選ぶのではなく、「ポートフォリオの補完性」で選ぶ：
- 少なくとも1社は「確実性が高く、上昇余地が低い」（ウォーレン・バフェット型）
- 少なくとも1社は「確実性が中程度で、上昇余地も中程度」（成長型）
- 任意で1社は「上昇余地が大きく、高リスク」（オプション型）

あるサブセクターで十分に優れた企業が3社見つからない場合は、数合わせをせず「最終2社 + ウォッチリスト1社」とする。

## ステップ4：4人の達人による深掘り分析（3社、1社800～1,200字）

最終選定した3社について、4人の達人の視点から詳細分析を行う。

### 4.1 段永平の視点：事業の本質

- この企業がどのような事業をしているか、一文で定義
- 優れた事業か？ その理由は？
- その企業の「本分」は何か？ 経営陣はそこから外れていないか？
- ビジネスモデルの「持続性」はどこにあるか？

### 4.2 ウォーレン・バフェットの視点：経済的な堀の深さ

- 5種類の経済的な堀を評価（★1～5）し、具体的な根拠を示す
- 10年後も経済的な堀は残るか？
- 現在買う場合の「安全余裕」はどこにあるか？

| 経済的な堀 | 強度 | 具体的な根拠 |
|-------|------|---------|
| ブランド／価格決定力 | | |
| スイッチングコスト | | |
| ネットワーク効果 | | |
| 規模の経済 | | |
| 技術／許認可の参入障壁 | | |

### 4.3 チャーリー・マンガーの視点：リスクと失敗パターン

- この企業は、どのように失敗する可能性が最も高いか？（上位3つの失敗経路を列挙）
- 最悪のシナリオでは、いくらの価値があるか？（極めて簡潔なバリュエーション）
- 賢い投資家が買わない理由は？（反対方向からの論証）
- 倫理／コンプライアンス／経営陣のリスクはあるか？

### 4.4 李録の視点：文明レベルのトレンド上の位置付け

- この企業が属する分野は「文明レベルのパラダイム転換」か、「一時的なブーム」か？
- 歴史上最も近い技術革命は何か？
- 10～20年後、この企業は最終的にどうなるか？
- 勝者総取りの構造か？

### 4.5 総合推奨度

```
推奨度：★★★★☆
ポジションの種類：中核 / サテライト / オプション / ウォッチリスト
推奨購入レンジ：現在値 / N%の調整後 / 辛抱強く待つ
推奨ポジションサイズ：当該テーマのポジションのX%
重要な監視指標：（この企業の投資ロジックが反転したことを示すシグナルは何か）
```

## ステップ5：統合出力

レポート末尾に統合する：

### 5.1 最終3社の組み合わせ表

| 企業 | 種類 | 推奨度 | 推奨ポジションサイズ | 中核となる投資ロジック | 重要リスク |
|------|------|-------|---------|---------|---------|
| A | 中核 | ★★★★★ | 50～60% | | |
| B | サテライト | ★★★★☆ | 25～35% | | |
| C | オプション | ★★★☆☆ | 5～15% | | |

### 5.2 業界ETFによる代替

個別銘柄を選びたくない場合は、関連ETFを1～3本挙げる（中国A株／香港株／米国株）。

### 5.3 業界全体の位置付け

- 業界PER／PBRの過去分位
- 資金フロー（中国本土・香港間のノースバウンド資金、ETFの設定・解約、セルサイドのカバレッジ密度）
- 全体として「初期／拡大／成熟／衰退」のどの段階にあるか

### 5.4 情報の充足度に関する自己評価（必須）

| 観点 | 評価 | 説明 |
|-----|------|-----|
| 企業の財務データの完全性 | A/B/C | |
| バリュエーションデータの鮮度 | A/B/C | |
| 業界構造の判断 | A/B/C | |
| 経営陣の情報 | A/B/C | |

A = データが十分で信頼できる、B = 一部不足するが主要な結論に影響しない、C = 不足が多く、結論には注意が必要。

### 5.5 更新待ちのデータ項目

どのデータが推定値か、どのデータを今後確認する必要があるか、どの四半期報告書を重点的に追跡するかを明記する。

### 5.6 情報源一覧

各データ／結論の情報源リンクを、決算、調査レポート、ニュース、業界レポートに分類して列挙する。

## AI調査におけるバイアスの自覚（重要）

ファネル・スクリーニングの過程で、AIが陥りやすい罠：

| バイアス | 現れ方 | 対応策 |
|------|-----|------|
| 業界大手への偏り | 大型株は資料が多く、分析の分量も長いため「より優れている」ように見える | 必須指標と経済的な堀で評価し、レポートの分量で順位付けしない |
| 英語への偏り | 米国株は資料が豊富で、中国A株・香港株は過小評価されやすい | 中国語と英語の両方で必ず検索し、中国A株／香港株を漏らさない |
| ストーリーへの偏り | 高い上昇率 + メディアの注目 = より優れた「AI関連株」に見える | 「AI事業の売上高比率」と「AIストーリーの比率」を区別し、実際の事業を見る |
| 現状への偏り | 現在の財務が優れた企業は選ばれやすく、変革期の有望企業を見逃す可能性がある | 第2層の一次選別では「傾向の改善」を緩和条件として認める |
| 上場企業への偏り | 上場企業だけを見ると、その分野で最良の企業を見逃す可能性がある | 「将来のIPO候補」を必ず列挙し、バリュエーションと時間枠を明記 |

## 出力要件

1. **レポートの保存場所**：`reports/{行业名}-funnel-{YYYYMMDD}.md`（業界レポートは `reports/` 直下に保存）
2. **言語**：日本語
3. **スタイル**：直接的で鋭く、無駄を省く
4. **データ**：すべてのデータに情報源を付記し、推定値には「推定」と明記
5. **立場を事前に決めない**：データを提示 → 投資ロジックを組み立てる → 結論を出す
6. **賛否両面**：各中核判断に反対方向の論拠を添える
7. **各層で除外記録を残す**：除外した企業も、企業名 + 理由を残す

## データの抜き取り検査（公開判定プロセス）

レポート保存後にデータの抜き取り検査を実行し、合格した場合のみ公開する：

```bash
# Step 1 — 抜き取り検査リストを抽出（15%を無作為抽出）
python3 tools/report_audit.py extract \
  --report <レポートファイルのパス>

# Step 2 — リストの各項目について信頼できる情報源から数値を取得（skills/financial-data.mdを参照）

# Step 3 — 公開可否の判定を出力
python3 tools/report_audit.py verdict \
  --results '<入力済みJSON>' \
  --report <レポートファイル名>
```

**【公開可】** すべて合格 → レポートを公開可能。**【差し戻し】** 不合格あり → 修正後に再審査。

- `/investment-checklist` —— ウォーレン・バフェット流の購入前チェックリストで体系的に確認
- `/management-deep-dive` —— 経営陣の詳細調査

`industry-funnel` は入口であり、後続のskillで深掘りする。
