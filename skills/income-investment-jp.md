# 日本株のインカム投資分析

## 目的

表示配当利回りではなく、分配原資、景気耐性、資本配分、税引前の円建て総収益を評価する。株主優待は現金配当と分離する。

## 分析項目

1. 配当方針：配当性向、DOE、累進配当、下限配当、記念配当を区別する。
2. 分配原資：営業CF、維持投資、成長投資、負債返済後の余剰資金を確認する。
3. 履歴：10年を目安に減配、無配、増配、自己株式取得、消却、増資を追う。
4. 景気耐性：不況、原材料高、金利上昇、為替変動時の利益・CFと配当余力を試す。
5. 資本効率：低収益資産、政策保有株、持合い、余剰現金と還元の整合を評価する。
6. 株主優待：対象株数、保有期間、廃止可能性、換金性を示し、主観的価値を配当に加算しない。
7. 評価：現在利回り、利益・FCF配当性向、DOE、三情景の配当成長と価格変化を計算する。

## 計算

```bash
python tools/financial_rigor.py --locale ja verify-valuation --price {株価} --eps {EPS} --bvps {BPS} --fcf-per-share {1株FCF} --dividend {年間配当}
python tools/financial_rigor.py --locale ja calc --expr '{正確な算式}'
```

## 判定

「安定分配」「循環的分配」「再建途上」「利回り罠」のいずれかを選び、減配条件、増配条件、買付価格帯、既存保有者の判断を示す。データ取得と監査は `skills/financial-data-jp.md` に従う。
