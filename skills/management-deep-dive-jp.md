# 日本企業の経営陣・資本配分の深掘り

`$ARGUMENTS` の会社または「人物名 会社名」について、公開情報だけで経営の誠実性、能力、資本配分、少数株主への公正さを検証する。

## 設計思想

経歴、持株、報酬だけで人物を判断しない。最低5年の発言と行動、重大な意思決定、その後の結果を追う。`skills/investment-research-jp.md` の経営評価が不確実、または経営者が投資仮説の中心である場合の深化版である。

公開情報からできること：

- 約束と実行を照合する。
- 大きな資本配分の成果を追う。
- 困難時の説明と行動から誠実性を見る。
- 従業員、顧客、取引先、業界の側面情報で検証する。

人物への噂や診断は行わず、事実・推論・不明を分ける。

肩書と実際の意思決定者を区別する。親会社、創業家、相談役等の影響も有価証券報告書、コーポレートガバナンス報告書、株主総会資料で確認する。

利用可能なら4つのAgentを並行起動する。

1. 公開発言、目標、予測、説明履歴。
2. 買収、売却、投資、配当、DOE、自己株式取得、増資。
3. 株主構成、取締役会、報酬、関連当事者、親子上場。
4. 従業員、顧客、取引先、品質・法令、業界評判。

各Agentは日付、原文要旨、出典、反証、確信度を返す。利用できない場合は順番に実行する。

## 第3段階：誠実性

誠実性は一票否決項目とする。

### 3.1 約束と実績

過去3～5年の数値目標と具体的行動を追う。

| # | 時点 | 約束 | 場所 | 期限 | 結果 | 評価 |
|---:|---|---|---|---|---|---|

- 80%超：高い一貫性。
- 60～80%：おおむね実行。
- 40～60%：要注意。
- 40%未満：重大な信頼問題。

単純な件数だけでなく、難易度、外部条件、目標変更の説明を併記する。曖昧な理念を「約束」に数えない。

### 3.2 困難時

業績未達、品質事故、会計問題、災害、規制、競争激化等について、初動、情報開示、責任の取り方、内部要因の認識、再発防止、結果を年表にする。

## 第8段階：報告

```text
1. 主要人物一覧
2. 誠実性：約束、危機、利害関係者
3. 能力：戦略、実行、修正
4. 資本配分の意思決定と成果
5. 統治：株主、報酬、関連当事者、少数株主
6. 側面検証と情報限界
7. 退任・後継シナリオ
8. 総合評価と投資仮説への影響
```

| 項目 | 重み | 1～5点 | 加重点 |
|---|---:|---:|---:|
| 誠実性 | 35% | | |
| 戦略・実行 | 25% | | |
| 資本配分 | 25% | | |
| 統治・少数株主 | 15% | | |

加重点だけで結論を出さず、誠実性1点は不適格とする。最後に「正直か」「能力があるか」「10年資本を預けられるか」を答える。

## 第9段階：保存と監査

`reports/{会社名}-management-{YYYYMMDD}.md` へ保存する。既存ファイルは上書きせず履歴を残す。

```bash
python tools/report_audit.py --locale ja extract --report {レポートパス} --market jp
python tools/report_audit.py --locale ja verdict --results '<照合済みJSON>' --report {レポート名} --market jp
```

数値・人物・日付に監査不合格があれば直して再実行する。行動を言葉より重く、逆風時を順風時より重く、能力を理由に誠実性を割り引かない。
