# 日本企業の経営陣・資本配分の深掘り

## 基本姿勢

人物評や記事の印象ではなく、少なくとも5年の意思決定と結果で評価する。創業者企業、親子上場、支配株主が存在する企業では、能力と少数株主への公正さを別々に採点する。

## 調査項目

1. 経歴、在任期間、後継計画、取締役会構成、指名・報酬制度。
2. 中期計画の過去目標と実績。未達時の説明、目標のすり替え、再発防止。
3. 設備投資、研究開発、採用、買収、事業売却の判断と投下資本利益率。
4. 配当、DOE、自己株式取得、消却、増資、転換証券の履歴。
5. 政策保有株式と持合いの縮減、余剰資産、現預金、負債の扱い。
6. 親子上場、支配株主、関連当事者取引、少数株主保護、特別委員会。
7. 役員報酬と株式保有。短期利益と長期価値のどちらへ連動しているか。
8. 不祥事、品質問題、会計問題、情報漏えい等への初動と再発防止。

## 資料

有価証券報告書、コーポレートガバナンス報告書、株主総会招集通知、適時開示、決算説明会資料、統合報告書を優先する。インタビューは発言の証拠であり、実行の証拠とは分ける。

## 評価

- 誠実性
- 資本配分能力
- 事業運営能力
- 少数株主への公正さ
- 後継者を含む組織再現性

回顧評価では、当時利用可能だった情報と現在判明した結果を分ける。自己株式取得時の評価水準は次で確認する。

```bash
python tools/financial_rigor.py --locale ja verify-valuation --price {取得時株価} --eps {当時EPS} --bvps {当時BPS}
```

## 出力

重要意思決定の年表、目標対実績、資本配分表、ガバナンス上の赤旗、経営者依存度、後継リスク、投資仮説への影響をまとめる。人物への断定は一次資料で裏付け、未確認情報を事実として書かない。
