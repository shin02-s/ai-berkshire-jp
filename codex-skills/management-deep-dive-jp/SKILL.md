# 経営陣の詳細調査：株式を買うことは人を買うこと

## 日本語版の共通実行ルール

- 株価、時価総額、財務数値、バリュエーションなどの通貨単位は、日本株では円（JPY）、米国株では米ドル（USD）を使用する。市場横断比較で換算する場合は、元の通貨を併記し、換算日と為替レートを明示する。
- レポートを保存・更新・検索する場合は、`reports/` ではなく `reports-jp/` 配下を使用する。
- データ取得・計算・検証には必要に応じて `tools/` の既存ツールを使用する。日本株では `python tools/jpstock_data.py quote {証券コード}` で株価、`financials` / `filings` でEDINETの財務・開示資料を取得し、重要数値は `tools/financial_rigor.py`、完成レポートは `tools/report_audit.py` で検証する。
- 競合・産業チェーンの調査では、日本・韓国・台湾・欧州・中国・米国など世界の関連企業を、上場市場や資料言語を理由に除外しない。ただし、特定の海外市場に固有のデータ取得手順、評価基準、通貨例は設けず、各社の公式IR・法定開示・取引所資料を優先する。

`$ARGUMENTS` の経営陣を詳細に調査する。

**対応する入力形式**：`企業名` または `人名 企業名`。例：`トヨタ`、`豊田章男 トヨタ`、`ジェンスン・フアン NVIDIA`

> 「株式を買うことは人を買うこと。信頼できる人を見つけ、長期保有する。」――段永平
>
> 「経営陣を評価するには、誰も見ていないときに何をするかを見る。」――ウォーレン・バフェット

## 設計思想

多くの投資分析における経営陣の評価は、経歴、持株比率、報酬といった表面的なものにとどまる。しかし、ウォーレン・バフェットは多くの時間をかけて**経営陣と食事をしながら話し**、李録は**投資の本質は人への投資だ**と述べ、段永平は**株式を買うことは人を買うことだ**と述べている。

このSkillは、`/investment-research` のステップ5「経営陣の評価」の**詳細版**である。標準的な投資調査で経営陣の評価が不確か（★★★以下）な場合、または経営陣が中核的な投資ロジックである場合に使用する。

AIは経営陣と食事を共にできないが、公開情報を通じて次を実行できる：
- **経営陣の発言と行動が一致しているか追跡する**（公約 vs 実績）
- **重大な資本配分の意思決定ごとにリターンを分析する**
- **困難な時期の意思決定から品格を推定する**
- **従業員／販売事業者／顧客の反応から間接的に検証する**

## 実行手順

### ステップ1：重要な経営陣を特定し、データ収集を並列で開始する

WebSearchで以下の重要人物を確認する：

| 役割 | 氏名 | 在任期間 | 経歴 | 持株／オプション |
|------|------|------|------|----------|
| CEO／会長 | | | | |
| CFO | | | | |
| 創業者（現職でない場合） | | | | |
| 実質的支配者（CEOと異なる場合） | | | | |
| その他の重要幹部 | | | | |

**注意**：「誰が意思決定しているか」と「誰の名前が肩書に載っているか」を区別する。一部企業では、創業者が退任後も精神的支柱であり続ける。

重要人物を確認後、Taskツールで複数のバックグラウンドAgentを起動し、以下のデータを**並列**収集する：
1. Agent 1：CEOの公開発言と予測実績（株主への書簡、決算説明会、インタビュー、SNS）
2. Agent 2：資本配分の意思決定実績（M&A、自社株買い、配当、新規事業投資）
3. Agent 3：ガバナンス構造と報酬（株式所有構造、関連当事者取引、役員報酬）
4. Agent 4：間接検証情報（従業員評価、顧客の反応、業界での評判）

### ステップ2：CEOの能力の輪を評価する

#### 2.1 戦略眼

過去5年間のCEOの公開発言（株主への書簡、決算説明会、インタビュー、SNS）を検索し、以下の問題への判断を抽出する：

| 時期 | CEOの判断／予測 | 実際の結果 | 正確性 |
|------|--------------|---------|:------:|
| | 「X市場は...になると考える」 | X市場の実際... | ✅/❌ |
| | 「今後3年間の重点は...」 | 実際の実行... | ✅/❌ |

**重要な問い**：
- CEOは市場に先行する正しい判断をしたことがあるか？
- 誰もが強気なときに、CEOは冷静さを保ったか？
- 業界トレンドへの理解は市場追随か、独立した思考か？

#### 2.2 実行力

| 観点 | 評価 | 根拠 |
|------|------|------|
| 戦略から実行へ | 発言したことを実行したか？ | |
| 組織能力 | 人材を引き付け、定着させられるか？ | |
| 危機対応 | 困難にどう対応したか？ | |
| 改善速度 | 誤りを犯した後、素早く修正できるか？ | |

### ステップ3：誠実性の評価（最重要）

**ウォーレン・バフェット**：「私たちは3つの資質を求める。誠実さ、知性、活力だ。最初の1つがなければ、残りの2つがあなたを破滅させる。」

#### 3.1 公約 vs 実績の追跡

過去3年間の決算説明会、株主への書簡、公開インタビューから、経営陣が行った**具体的な公約**を抽出する：

| # | 時期 | 公約内容 | 公約した場 | 達成状況 | 評価 |
|---|------|---------|---------|---------|------|
| 1 | | 「2025年にX事業を黒字化する」 | 2024年次決算説明会 | | ✅/⚠️/❌ |
| 2 | | 「X億米ドルの自社株買いを計画」 | 2024年株主への書簡 | | ✅/⚠️/❌ |

**達成率の集計**：

| 公約達成率 | 評価 |
|:---------:|------|
| 80%超 | 優秀――有言実行 |
| 60～80% | 合格――大きな方向性は正しいが、実行にずれがある |
| 40～60% | 懸念――公約が多い一方、実行が不十分 |
| 40%未満 | 重大な問題――信頼できない |

#### 3.2 困難な時期の行動

企業が過去に直面した重大な危機／困難（株価急落、業績未達、規制ショック、競争激化）を検索し、経営陣の対応を分析する：

| 危機イベント | 時期 | 経営陣の対応 | 事後評価 |
|---------|------|-----------|-------------|

**注目点**：
- 積極的に説明したか、それとも逃げたか？
- 原因を社内に求めたか、外部へ責任転嫁したか？
- 困難でも正しいことを行ったか、短期的に市場へ迎合したか？

#### 3.3 ステークホルダーへの姿勢

| ステークホルダー | 経営陣の姿勢 | 根拠 | 評価 |
|-----------|-----------|------|------|
| 株主 | 尊重／無視／利用 | | |
| 従業員 | 大切にする／搾取／無関心 | | |
| 顧客／ユーザー | 顧客中心／短期的に搾り取る | | |
| 販売事業者／サプライヤー | 公正な協力／極端な値下げ圧力 | | |
| 規制当局／社会 | コンプライアンスに協力／規制の境界を狙う | | |

**李録**：「ステークホルダーへの姿勢が企業の長期的な生命力を決める。短期的な搾取は効率を高めるが、長期的にはエコシステムを損なう。」

### ステップ4：資本配分能力

これはウォーレン・バフェットが最も重視する経営陣の能力である――**1の利益を得るたびに、経営陣はそれをどれだけの価値へ増やせるか？**

#### 4.1 資本配分の意思決定実績

過去5年間の重大な資本配分の意思決定を検索し、1件ずつ評価する：

**M&Aの実績**：

| 時期 | 買収対象 | 金額 | 戦略上の投資ロジック | 事後リターン | 評価（1～5） |
|------|---------|------|---------|---------|:---------:|

**自社株買いの実績**：

`tools/financial_rigor.py verify-valuation` で、自社株買い時と現在のPERなどのバリュエーション指標を検証する。

| 時期 | 自社株買い額 | 平均買付価格 | 当時のPER | 事後評価 | 評価（1～5） |
|------|---------|-----------|:------:|---------|:---------:|

**配当の実績**：

| 年 | 配当額 | 配当性向 | 同期のフリーキャッシュフロー | 持続可能か |
|------|---------|:------:|---------|:---------:|

**新規事業への投資**：

| 時期 | 投資分野 | 累計投資額 | 現在の状況 | リターン評価 | 評価（1～5） |
|------|---------|---------|---------|---------|:---------:|

#### 4.2 資本配分の評価

| 観点 | 評価（1～5） | 説明 |
|------|:---------:|------|
| M&Aの規律 | | 妥当な価格で買収したか？ 買収後の統合はどうか？ |
| 自社株買いのタイミング | | 割安時に買い、割高時に停止したか？ |
| 配当の妥当性 | | 配当性向はフリーキャッシュフローと一致するか？ |
| 新規事業への投資 | | 成功率はどうか？ 損切りの規律はどうか？ |
| 現金管理 | | 現金準備は妥当か？ 過剰に蓄積していないか？ |
| **総合評価** | | |

**ウォーレン・バフェットの基準**：理想的な経営陣は、良い機会があるときに果断に投資し、良い機会がないときは積極的に自社株買い／配当を行い、高値でのM&Aは決して行わない。

#### 段永平の「人を買う」基準

> 次の3つの問いに答える：
> 1. **この人は誠実か？**（正直で、株主から不当に利益を得ない）
> 2. **この人は有能か？**（戦略眼 + 実行力 + 資本配分）
> 3. **この人に10年間、資金を預けたいか？**
>
> 3つとも「はい」= ★★★★★（5点）
> 最初の2つが「はい」= ★★★★（4点）
> 最初の1つだけが「はい」= ★★★（3点）
> 最初が「いいえ」= ★（1点、投資しない）

## 重要原則

- **誠実性は一発で否決となる項目**――能力不足は学習できるが、人格の問題は修復できない
- **言葉ではなく行動を見る**――経営陣が何を言うかではなく、何をしたかが重要
- **困難なときに真実を見る**――追い風では誰もが優れたCEOに見える。向かい風で本当の実力が分かる
- **資本配分が最終試験**――利益を得るのは容易でも、得た利益を適切に配分するのは難しい
- **経営陣に恋をしない**――客観性を保つ。高く評価する人物でも重大な誤りを犯し得る
