# 日本株の業界漏斗スクリーニング

## 目的

指定業界の東証上場企業を母集団として、事業適合、財務耐久性、競争優位、経営・ガバナンス、評価の順に絞り、深掘り候補を最大3社にする。

## 漏斗

1. **母集団**：東証プライム・スタンダード・グロースの内国普通株を列挙し、事業構成比を確認する。
2. **除外**：対象事業の比率が小さい、開示不足、継続企業懸念、過大債務、重大な誠実性問題を除く。
3. **財務品質**：3〜5年の売上、利益、営業CF、ROIC、ROE、負債、希薄化、景気循環を比較する。
4. **競争優位**：価格決定力、顧客維持、規模、技術、認証、コスト、希少資産を比較する。
5. **経営・ガバナンス**：資本配分、政策保有株、親子上場、支配株主、少数株主保護を確認する。
6. **評価**：円建て時価総額と倍率を同一時点・同一会計口径で比較する。
7. **最終候補**：上位3社までに絞り、各社の深掘りすべき争点と見送り条件を示す。

母集団からの除外理由を必ず残す。データがない企業を低得点と断定せず「判定不能」とする。

## データと監査

`skills/financial-data-jp.md` に従い、海外企業は産業構造の説明に限る。国外上場銘柄をランキングへ加えない。

```bash
python tools/report_audit.py --locale ja extract --market jp --report reports/{業界}-industry-funnel-{YYYYMMDD}.md
python tools/report_audit.py --locale ja verdict --market jp --results '<検証済みJSON>' --report {業界}-industry-funnel-{YYYYMMDD}.md
```

## 出力

母集団一覧、各段階の除外表、横比較表、最終3社、候補ごとの最大リスク、追加調査項目、データ欠損を記載する。
