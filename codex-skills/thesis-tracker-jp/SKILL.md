## Codexアダプター注記

このスキルは `skills/thesis-tracker-jp.md` から生成され、Claude Code とCodexで正本を共有する。

- `$ARGUMENTS` は現在のCodexタスクにおけるユーザー依頼として扱う。
- 利用できる検索、シェル、ファイル編集機能を使い、必要な調査と検証を行う。
- 共通ツールはリポジトリ直下から実行し、日本版では `--locale ja`、必要に応じて `--market jp` / `--currency JPY` を付ける。
- 調査前に `date` で当日を確認し、データ基準日をレポート冒頭に記載する。
- `AGENTS.md` の品質規則に従い、財務数値の照合、正確な計算、欠損と不確実性を明示する。

# 日本株の投資仮説トラッカー

## 初期登録

- 会社名、証券コード、市場区分、登録日、株価基準日
- 投資仮説を支える3〜5個の事実
- 主要KPIと期待レンジ
- 経営・資本配分・ガバナンス上の前提
- 円建て評価範囲と期待収益
- 仮説撤回条件、縮小条件、追加条件

## 更新タイミング

決算、業績修正、配当・DOE変更、自己株式取得、増資、M&A、社長交代、不祥事、規制変更、重要な顧客・供給者変化の後に更新する。株価だけの変化では事業仮説を書き換えない。

## 更新項目

1. 新しい事実と情報源。
2. KPIの期待差と原因。
3. 競争優位の拡大・維持・縮小。
4. 資本配分、政策保有株、親子上場、少数株主保護の変化。
5. 株式数、EPS、BPS、配当、時価総額、評価倍率。
6. 仮説判定：強化・不変・弱化・破綻。
7. 次の観測日と行動条件。

```bash
python tools/financial_rigor.py --locale ja verify-valuation --price {株価} --eps {EPS} --bvps {BPS} --dividend {配当}
```

## 規律

事実、解釈、希望を分離する。撤回条件に触れた場合は、代替理由を探す前に破綻可能性を評価する。最新データは `skills/financial-data-jp.md` に従って照合する。
