# 投資仮説の追跡：購入後の規律システム

## 日本語版の共通実行ルール

- 株価、時価総額、財務数値、バリュエーションなどの通貨単位は、日本株では円（JPY）、米国株では米ドル（USD）を使用する。市場横断比較で換算する場合は、元の通貨を併記し、換算日と為替レートを明示する。
- レポートを保存・更新・検索する場合は、`reports/` ではなく `reports-jp/` 配下を使用する。
- データ取得・計算・検証には必要に応じて `tools/` の既存ツールを使用する。日本株では `python tools/jpstock_data.py quote {証券コード}` で株価、`financials` / `filings` でEDINETの財務・開示資料を取得し、重要数値は `tools/financial_rigor.py`、完成レポートは `tools/report_audit.py` で検証する。
- 競合・産業チェーンの調査では、日本・韓国・台湾・欧州・中国・米国など世界の関連企業を、上場市場や資料言語を理由に除外しない。ただし、特定の海外市場に固有のデータ取得手順、評価基準、通貨例は設けず、各社の公式IR・法定開示・取引所資料を優先する。

`$ARGUMENTS` に投資仮説の追跡チェックを実行する。

**対応する入力形式**：
- `企業名` — 初回は投資仮説を作成し、以後は追跡チェック
- `企業名 投資仮説を作成` — 投資仮説を強制的に再作成
- `企業名 四半期チェック` — 最新の決算に基づいて投資仮説を確認

> 「購入は始まりにすぎない。本当の仕事は、保有期間中の継続的な追跡である。」――李録
>
> 「事実が変われば、私は考えを変える。あなたは？」――ケインズ

## 設計思想

多くの投資家のプロセスは、調査 → 購入 → 祈る、である。購入後の体系的な追跡がないため、次の問題が生じる：
- 売るべきときに売れない（「もう少し待てば、戻るはず」）
- 売るべきでないときに恐怖で売る（「20%下がった。判断が間違っていたのか」）
- 当初の購入理由を忘れる（「これは何が理由で買ったのだろう？」）

ウォーレン・バフェットと李録の方法は、**購入前に売却条件を書いておくこと**である。その後、四半期ごとに投資仮説が完全かを確認する。

## 実行手順

### ステップ1：動作モードを判断する

当該企業の投資仮説ファイル（`reports-jp/{企業名}-thesis.md`）があるか確認する：
- 存在しない → **投資仮説の作成**モード
- 存在する → **追跡チェック**モード
- 見つからないが、ユーザーが存在すると述べる → ファイルパスを確認

## モードA：投資仮説を作成する

### A0：データ収集

WebSearchで現在の株価、バリュエーション指標（PER／PBR／配当利回り）、最新決算の中核データを取得し、バリュエーション基準点を記入する。当該企業の `/investment-research` または `/investment-team` レポートがある場合は、そこから優先的に読み込む。

`tools/financial_rigor.py verify-valuation` でバリュエーションデータを検証する。

### A1：中核となる投資仮説（必ず200字以内で明確にする）

投資仮説は次の5つの問いに答える。各問いは1文とする：

```
私は___元で___社を買う。その理由は：
1. この事業の本質は___であり、利益の仕組みを理解している
2. 経済的な堀は___であり、広がっている／安定している
3. 経営陣は___であり、信頼できる理由は___
4. 現在の価格は本源的価値の___%に相当し、安全余裕は___から生じる
5. 判断が誤っていても、下方リスクは制御可能である。その理由は___
```

**5文を完成できない場合、投資仮説自体に問題がある――購入判断が不明確であることを意味する。**

### A2：中核仮定一覧

投資仮説を検証可能な具体的仮定へ分解する：

| # | 中核仮定 | 検証方法 | 検証頻度 | 現在の状態 |
|---|---------|---------|---------|---------|
| 1 | 例：売上高成長率を15%以上に維持 | 四半期報告書の売上高成長率 | 四半期ごと | 🟢 成立 |
| 2 | 例：粗利率が60%以上で安定 | 四半期報告書の粗利率 | 四半期ごと | 🟢 成立 |
| 3 | 例：経営陣が自社株買いを継続 | 自社株買い開示／キャッシュフロー計算書 | 四半期ごと | 🟢 成立 |
| 4 | 例：競合が突破していない | 業界データ／競合の決算 | 半年ごと | 🟢 成立 |
| 5 | ... | ... | ... | ... |

通常は3～7個の仮定とする。少なすぎる場合は思考が浅く、多すぎる場合は投資仮説の焦点が定まっていない。

### A3：レッドライン一覧（1つでも発動 = 必ず再評価）

| # | レッドライン条件 | 深刻度 | 発動後の行動 |
|---|---------|---------|-----------|
| 1 | 例：経営陣の誠実性に問題（粉飾決算、関連当事者取引） | 致命的 | 直ちに全売却 |
| 2 | 例：中核事業の売上高が2四半期連続で減少 | 深刻 | ポジションを50%縮小し、再評価 |
| 3 | 例：経済的な堀が明確に突破される（競合が同等の能力を獲得） | 深刻 | 詳細調査を開始し、撤退を検討 |
| 4 | 例：規制政策がビジネスモデルを根本から変更 | 深刻 | 本源的価値を再評価 |
| 5 | 例：経営陣の大規模な売却（計画に基づかないもの） | 警告 | 理由を詳細調査 |

**段永平**：「売却理由は3つだけ。1. 買い間違いに気付いた。2. 企業のファンダメンタルズが変わった。3. より良い投資機会を見つけた。」

### A4：バリュエーション基準点

| 指標 | 購入時 | 強気目標 | 中立目標 | 弱気シナリオ |
|------|-------|---------|---------|---------|
| 株価 | | | | |
| PER | | | | |
| 時価総額 | | | | |
| 本源的価値の推定 | | | | |

### A5：投資仮説を保存する

投資仮説を `reports-jp/{企業名}-thesis.md` に保存し、以下を含める：

## モードB：追跡チェック

### B1：既存の投資仮説を読み込む

`reports-jp/{企業名}-thesis.md` を読み、以下を読み込む：
- 中核となる投資仮説
- 中核仮定一覧
- レッドライン一覧
- 前回のチェック記録

### B2：最新データを収集する

WebSearchで以下を収集：
1. 最新の決算データ（新しい四半期報告書／年次報告書がある場合）
2. 直近の重大イベント（経営陣の変更、規制政策、競争動向）
3. 現在の株価とバリュエーション指標
4. インサイダー取引の記録（大株主の買い増し／売却）

### B3：中核仮定を項目ごとに確認する

各中核仮定を最新データで検証する：

| # | 中核仮定 | 前回の状態 | 最新の証拠 | 現在の状態 | 変化 |
|---|---------|---------|---------|---------|------|
| 1 | 売上高成長率15%以上 | 🟢 成立 | Q4売上高成長率12% | 🟡 限界的に弱化 | ⚠️ |
| 2 | 粗利率60%以上 | 🟢 成立 | 粗利率61.2% | 🟢 成立 | — |
| 3 | ... | ... | ... | ... | ... |

状態の定義：
- 🟢 **成立** — 最新データが仮定を支持
- 🟡 **限界的に弱化** — データは許容範囲内だが、傾向は不利
- 🔴 **毀損** — データが明確に仮定を支持しない
- ⚫ **崩壊** — 仮定が覆された

### B4：レッドラインの確認

レッドライン一覧を項目ごとに確認する：

| # | レッドライン条件 | 発動したか | 証拠 |
|---|---------|:-------:|------|
| 1 | 経営陣の誠実性の問題 | ❌ 未発動 | — |
| 2 | 中核事業が2四半期連続で減少 | ❌ 未発動 | — |

**レッドラインが1つでも発動した場合は、レポート内で目立つように表示し、明確な行動案を示す。**

### B5：バリュエーションを更新する

| 指標 | 購入時 | 前回チェック | 現在 | 変化 |
|------|-------|---------|------|------|
| 株価 | | | | |
| PER（TTM） | | | | |
| 本源的価値の推定 | | | | |
| 安全余裕 | | | | |

### B6：追跡レポートを出力する

#### レポート構成

```
1. 投資仮説の健全度スコア（10点満点）
2. 中核仮定の確認結果（表）
3. レッドラインの確認結果（表）
4. 当期の重要な変化（500字以内）
5. バリュエーションの更新
6. 結論と行動案
7. 次回チェックで注目すべき重点項目
```

#### 投資仮説の健全度評価基準

| スコア | 意味 | 推奨行動 |
|:----:|------|---------|
**計算式**：健全度 = 10 -（⚫崩壊した仮定数 × 3）-（🔴毀損した仮定数 × 2）-（🟡弱化した仮定数 × 1）-（発動したレッドライン数 × 5）。最低1点、最高10点。

| スコア | 意味 | 推奨行動 |
|:----:|------|---------|
| 9～10 | すべての仮定が成立し、投資仮説は購入時より強い | 買い増しを検討 |
| 7～8 | 中核仮定は成立し、一部が限界的に弱化 | 保有継続 |
| 5～6 | 1～2個の仮定が毀損したが、中核ロジックは不変 | 保有するが警戒を強める |
| 3～4 | 複数の仮定が毀損し、投資仮説の基礎が揺らぐ | ポジション縮小を検討 |
| 1～2 | レッドラインが発動、または中核仮定が崩壊 | 売却を強く推奨 |

#### 結論で必ず明確に答えること

1. **投資仮説はまだ完全か？** 完全 / 限界的に弱化 / 毀損 / 崩壊
2. **どうすべきか？** 買い増し / 保有 / ポジション縮小 / 全売却
3. **次回チェック時期**：次の四半期報告書の発表後 / 特定イベント後

## 重要原則

- **購入前に売却条件を書いておく**――冷静なときの意思決定は、恐怖に陥ったときの意思決定より優れている
- **投資仮説は検証できるほど具体的にする**――「企業は優れている」は投資仮説ではない。「自己資本利益率25%超で傾向が安定」が投資仮説である
- **レッドラインが発動したら行動する**――最も危険なのは「もう少し様子を見る」ことであり、大きな損失の始まりとなる
- **投資仮説の崩壊 ≠ 株価下落**――株価が30%下落しても売る必要はない場合がある。投資仮説が崩壊したときに売る
- **誤りに正直であること**――投資仮説の構築が誤っていたなら認める。面子のために固執しない
