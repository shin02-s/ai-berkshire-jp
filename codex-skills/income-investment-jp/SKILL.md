# 日本株インカム投資分析

`$ARGUMENTS` について、次を答える。

> この企業は、長期の中核インカムまたは条件付きの高利回り機会として、組合内の役割を正当化できる持続的な分配を生むか。

表示利回りの高さを投資機会の証拠にしない。本スキルは調査・学習用であり、個別の投資助言ではない。

## 入力

```text
/income-investment-jp "会社名または証券コード" [mode=new|existing] [role=core-income|opportunistic-income|unspecified] [quantity=...] [cost_basis=...] [portfolio_weight=...] [target_yield=...] [tax_residence=...] [account_type=...] [portfolio_file=...] [horizon=...]
```

会社名またはコードだけ必須。自然文も受け付ける。欠落値を推測せず「不明」「計算不能」とし、何が計算できないか説明する。税務上の居住地、口座種別、適用税率が不明なら税引後収入を推定しない。

対象は東証内国普通株。ETF、REIT、外国株は除外する。

## 調査規律

1. 調査開始時に日付を確認し、データ截止日を報告冒頭へ置く。
2. 有価証券報告書、決算短信、適時開示、会社IR、JPXを優先し、二次資料は不足補完と表示する。
3. 重要な財務数値は可能な限り二つの独立情報源で照合し、1%超の差は理由を確認する。
4. 時点数値に日付、期間数値に対象期間を付ける。重要記述を「確認済み事実」「推定」「仮定」「分析判断」に分ける。
5. 利回り、配当性向、時価総額、組合収入、三情景は暗算せず共通ツールを使う。
6. 保存後に数値抽出と判定監査を行い、不合格稿を公開可能とみなさない。

## 実行手順

### 1. 依頼の解析とデータ品質

証券、上場区分、JPY建て分配、保有モード、希望役割、数量、取得価額、比率、期間を整理する。総収入、税引後収入、取得価額利回り、組合収入寄与、取引後収入のうち計算可能なものを明示する。

- A：一次資料が十分で二経路照合可能。
- B：一次資料はあるが一部欠落・推定。
- C：二次資料中心または重要情報不足。

Cで中核判断に必要な情報がない場合は `データ不足` 門を発動する。

### 2. 分配を理解する

可能なら10年、最低5年について確認する。

- 年間配当、一株配当、普通・特別・記念・変動配当の区別。
- 配当性向、DOE、累進配当、下限配当の方針と実績。
- 増配、据置、減配、無配の回数。
- 特別配当を除いた配当成長率と計算期間。
- 権利付最終日、権利落ち日、基準日、支払予定日。
- 自己株式取得枠、実績、平均取得価額、消却。
- 株主優待の対象株数、保有期間、費用、換金性、廃止履歴。

権利落ちを無料利益と扱わない。日程は執行の参考にはなるが、弱い企業を買う理由や必要な売却を遅らせる理由にはならない。

### 3. 分配可能な現金を追う

純利益配当性向、FCF配当性向、維持投資後CF、成長投資、利払い、純有利子負債、満期、借換、リース、偶発債務、配当と競合する自己株式取得を確認する。

```bash
python tools/financial_rigor.py --locale ja verify-valuation --price {株価} --eps {EPS} --bvps {BPS} --fcf-per-share {1株FCF} --dividend {年間配当}
python tools/financial_rigor.py --locale ja calc --expr '{配当性向または利回りの算式}'
```

業種によって機械的なEPS配当性向を使わない。

| 業種 | 追加確認 |
|---|---|
| 銀行 | CET1、配当可能利益、規制資本、与信費用 |
| 保険 | ソルベンシー、保険契約利益、資本創出 |
| 資源 | 中間循環CF、変動配当方針、資源価格感応度 |
| 通信・電力 | 維持投資、負債、規制、FCFカバー |
| 商社 | 資産売却益、資源感応度、基礎営業CF |

### 4. 品質と持続性

事業モデル、競争優位、価格決定力、循環性、金利・為替・商品感応度、収入予測可能性、資本配分、経営品質を調べる。利益と反復可能な分配原資を分け、保守シナリオで分配が維持できるか確認する。

政策保有株の売却益、資産売却益、補助金で支えられた一時的分配を通常利益と混ぜない。親子上場、支配株主、少数株主保護も門として扱う。

### 5. インカムの評価

現在利回り、過去平均利回り、適切な業種倍率、FCF利回り、価値範囲、安全余地、株価下落と減配の複合シナリオを示す。取得価額利回りは過去情報であり、保有継続の根拠にしない。

### 6. 利用可能な収入を計算する

入力が足りる場合だけ、年間総配当、支払回ごとの総配当、既知の源泉、概算税引後収入、組合収入への寄与、取引後の年間収入を計算する。税務情報が不足する場合は税引前だけ示し、税引後を計算できない理由を書く。

株主優待は主観的価値を現金配当に加算せず、別欄で扱う。

### 7. 組合への適合

組合が提供された場合、現在・取引後比率、業種集中、共通利益要因、配当源の集中、最新の `portfolio-review-jp` を確認する。結論が異なる場合は両方を示し、企業品質と配分適合性を分離する。

良いインカム企業でも、集中し過ぎなら「保有・追加しない」「縮小」「監視」となり得る。月別総収入は計算可能なときだけ示し、空白月を埋めるために劣後企業を選ばない。

### 8. 三情景

基準、悪化、深刻の三つを作る。それぞれに、事業仮定、分配可能CF、配当カバー、財務・借換への影響、配当結果、評価への影響を置く。悪化と深刻では減配を明示的に検証し、配当固定を仮定しない。

```bash
python tools/financial_rigor.py --locale ja three-scenario --price {株価} --eps {EPS} --shares {株式数_億株} --growth {基準} {悪化} {深刻} --pe {基準PER} {悪化PER} {深刻PER} --currency JPY
```

## 分類、遮断門、結論

### 分類

- **中核・持続インカム**：質の高い事業、持続・成長可能な配当、長期保有可能性。
- **機会型インカム**：一時的な割引・高利回り。入口、監視、保有期限、退出規則が必須。
- **利回り罠**：カバー不足、過大負債、構造衰退、株価下落だけが作る高利回り。
- **インカム不適合**：分配が小さい、証拠不足、または株主還元の中心が別手段。

数値平均を作らず、各項目を `強い／十分／弱い／重大／不明` で評価する。

| 項目 | 評価 | 証拠 |
|---|---|---|
| 事業品質 | | |
| CF可視性 | | |
| 配当カバー | | |
| 財務耐久力 | | |
| 分配履歴 | | |
| 増配余地 | | |
| 評価 | | |
| 循環性 | | |
| 減配リスク | | |
| 組合適合性 | | |

### 遮断門

- 継続的な未カバー配当。
- 重大な債務・借換リスク。
- 構造的な事業悪化。
- 基礎情報不足。
- 重大な統治・誠実性問題。

安全、債務、悪化、誠実性の門に失敗したら、評点で相殺せず原則 `却下／利回り罠`。既存保有で即時処分を判断できない場合は `縮小`。情報不足は `データ不足`。

次から一つだけ返す。

- `中核インカム`
- `機会型インカム`
- `監視リスト`
- `保有・追加しない`
- `縮小`
- `却下／利回り罠`
- `データ不足`

結論には、可能な役割、主理由、最大リスク、入口条件、検討する比率範囲、強化条件、縮小・退出条件、監視指標、確信度を含める。

次の見出しを一度ずつ使い、同じ分析を繰り返さない。

5. 配当履歴と日程

10. 税務と通貨
11. 組合適合性
12. 基準・悪化・深刻シナリオ
13. 減配リスク
14. 買付・追加条件
15. 縮小・売却条件
16. 監視表
17. 一文結論
18. 出典とデータ品質

`reports/{会社識別子}-income-investment-{YYYYMMDD}.md` へ保存する。第2節に評価表と遮断門、第11節に計算可能なら月別収入、第18節に資料名、発行者、公開日、参照日、対象期間、URL、一次／二次を含める。
