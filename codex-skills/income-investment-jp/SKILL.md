# インカム投資：持続型および機会型の分配分析

## 日本語版の共通実行ルール

- 株価、時価総額、財務数値、バリュエーションなどの通貨単位は、日本株では円（JPY）、米国株では米ドル（USD）を使用する。市場横断比較で換算する場合は、元の通貨を併記し、換算日と為替レートを明示する。
- レポートを保存・更新・検索する場合は、`reports/` ではなく `reports-jp/` 配下を使用する。
- データ取得・計算・検証には必要に応じて `tools/` の既存ツールを使用する。日本株では `python tools/jpstock_data.py quote {証券コード}` で株価、`financials` / `filings` でEDINETの財務・開示資料を取得し、重要数値は `tools/financial_rigor.py`、完成レポートは `tools/report_audit.py` で検証する。
- 競合・産業チェーンの調査では、日本・韓国・台湾・欧州・中国・米国など世界の関連企業を、上場市場や資料言語を理由に除外しない。ただし、特定の海外市場に固有のデータ取得手順、評価基準、通貨例は設けず、各社の公式IR・法定開示・取引所資料を優先する。

`$ARGUMENTS` を分析し、次の問いに答える：

> この企業は、長期的なインカム確信銘柄または機会型の高利回りポジションとして、ポートフォリオに組み入れるに値するほど持続的で魅力的な分配可能利益を生み出せるか？

表示上の配当利回りが高いことを、良い投資機会の証拠として扱ってはならない。このワークフローは学習と調査を目的とし、個別の投資助言ではない。

## 入力

次のコマンド形式を使用する：

```text
/income-investment "<企業名またはティッカー>" [mode=new|existing] [role=core-income|opportunistic-income|unspecified] [quantity=...] [cost_basis=...] [portfolio_weight=...] [target_yield=...] [tax_residence=...] [portfolio_file=...] [horizon=...]
```

企業名またはティッカーは必須。その他のフィールドはすべて任意。同等の自然言語入力も受け付ける。不足する値を作り出してはならない。`不明` または `計算不可` と記載し、その影響を説明する。特に、税務上の居住地、口座種別、適用される租税条約、確定した源泉徴収の取扱いが分からない場合は、税引後インカムを推定してはならない。

## 調査規律

1. 調査前に `date` を実行する。レポートのヘッダーにデータ基準日を記載する。
2. 年次・中間報告書、決算発表資料、投資家向け資料、法定開示、公式発表、取引所の公式データの順で優先する。二次情報は不足を補う場合のみ使用し、二次情報であると明記する。
3. `skills/financial-data-jp.md` を適用する：意思決定に重要な財務データは、利用可能な場合、少なくとも2つの独立した情報源で検証し、1%を超える差異に印を付ける。
4. 時間の影響を受けるすべての数値に日付または期間を付ける。重要な記述をそれぞれ**検証済みの事実**、**推定**、**仮定**、**分析上の判断**に分ける。
5. 配当性向、利回り、バリュエーション、時価総額、ポートフォリオ・インカム、シナリオの正確な計算には `python3 tools/financial_rigor.py` を使用する。意思決定に重要な結果を暗算に頼ってはならない。
6. レポート保存後、`tools/report_audit.py extract` と `verdict` のワークフローを実行する。監査に不合格のレポートは草稿であり、公開可能な調査ではない。

## 実行ワークフロー

### 1. 依頼を解析し、データ品質を確定する

- 対象証券、上場市場、通貨、分配通貨、モード、希望する役割、任意のポートフォリオ入力を特定する。
- グロスインカム、ネットインカム、取得価格ベース利回り、ポートフォリオへの寄与、取引後の計算のうち、何が可能かを明記する。
- 証拠の質を `A`（完全な一次資料）、`B`（部分的な一次資料）、`C`（主に二次情報／不完全）で評価する。ファンダメンタルズの情報が重大な点で不足する場合は、`INSUFFICIENT DATA` ゲートを発動する。

### 2. 分配を理解する

可能な場合は少なくとも5年間を対象とする：

- 頻度、普通配当・特別配当・変動配当の別、支払通貨
- 1株当たり年間配当と分配総額
- 増配、据え置き、減配、停止の回数
- 配当の年平均成長率。正確な対象期間と特別配当の取扱いを明記
- 発表日、権利落ち日、基準日、支払日の目安

権利落ち日まで待っても、無償の利益にはならないことを説明する。理論上、株価は分配額だけ調整される。配当日程は執行タイミングの参考にはなるが、質の低い企業を買う理由や、必要な売却を遅らせる理由にしてはならない。

### 3. 分配可能な現金を追跡する

純利益ベースの配当性向、フリーキャッシュフロー・ベースの配当性向、必要な投資後のキャッシュフロー、キャッシュフローの安定性と質、利払い能力、純負債、負債満期、借り換え需要、維持設備投資と成長設備投資、関連するオフバランスのコミットメント、配当と競合する自社株買いを分析する。

EPSベースの配当性向を、すべてのセクターに機械的に適用してはならない：

| セクター | 必須のセクター指標 |
|---|---|
| REIT／SIIC | FFO、AFFO、稼働率、LTV |
| 銀行 | CET1、分配可能利益、規制上の制約 |
| 保険会社 | ソルベンシーと資本創出力 |
| BDC | NII、NAV、未収利息計上停止債権 |
| 資源 | サイクル中間点のキャッシュフローと変動分配方針 |
| 通信／公益 | 設備投資、負債、フリーキャッシュフローによるカバレッジ |

### 4. 質と持続性を検証する

ビジネスモデル、経済的な堀、価格決定力、景気循環性、金利／通貨／商品価格への感応度、インカムの予見可能性、資本配分、経営陣の質、下方シナリオでも分配を維持できる能力を評価する。会計上の利益と、反復可能な分配可能キャッシュを区別する。

### 5. インカムの流列を評価する

現在の配当利回り、過去平均利回り、適切なセクター倍率、フリーキャッシュフロー利回り、妥当な本源的価値のレンジ、安全余裕、株価下落と減配を組み合わせたシナリオを分析する。取得価格ベース利回りは過去の情報にすぎず、ポジションを維持する理由にしてはならない。

### 6. 利用可能なインカムを計算する

入力情報が十分な場合に限り、年間グロス配当、支払頻度ごとのグロス配当、既知の源泉徴収、推定ネットインカム、ポートフォリオ・インカムへの寄与、提案取引後の年間インカムを計算する。税務または口座情報が不完全な場合は、グロスインカムを表示し、ネットインカムを計算できない理由を正確に説明する。租税条約上の税率と税務上の取扱いには、法域、口座に関する仮定、発効日を明記する。

### 7. ポートフォリオとの適合性を確認する

ポートフォリオが提供された場合：

- 現在および提案後のウェイトを算出する
- セクター・地域の集中度、重複するリスク、単一業界へのインカム依存を調べる
- 資本の分散と配当の分散を区別する
- 利用可能な場合、関連する最新の `portfolio-review` レポートを読む

結論が異なる場合は、両方の結論を示し、理由を説明し、企業の質と配分上の適合性を分ける。優れたインカム証券でも、ポートフォリオの集中を理由に `HOLD – DO NOT ADD`、`REDUCE`、`WATCHLIST` が適切な場合がある。

データが許す場合は、月別の予想グロスインカムを表示する。配当のない月を埋めるために劣った企業を推奨してはならない。四半期配当銘柄を組み合わせれば、毎月配当銘柄に頼らず月次キャッシュフローを作れる。

### 8. 3つのシナリオを構築する

基本、悪化、深刻の3ケースを提示する。各ケースで、事業上の仮定、分配可能キャッシュフロー、配当カバレッジ、バランスシート／借り換えへの影響、配当結果、バリュエーションへの影響を示す。悪化ケースと深刻ケースでは、配当が固定されると仮定せず、減配を明示的に検証する。

## 分類、ゲート、最終判断

まずインカムの特性を分類する：

- **確信 + 持続可能なインカム**：質の高い事業、持続可能で成長する可能性のある配当、長期保有が妥当
- **機会型インカム**：一時的な高利回りまたはディスカウント。明確な参入、監視、保有期間、撤退ルールを持つ
- **利回りの罠**：カバレッジ不足の常態化、負債／投資需要との不整合、構造的衰退、または主として株価下落によって生じた高利回り
- **インカム目的に不適**：有意な分配がない、利回りが小さい、証拠不足、または株主還元の主な方法が別にある

次の定性的な評価表を使用し、数値平均は計算しない：

| 項目 | 評価（`Strong`、`Adequate`、`Weak`、`Critical`、`Unknown`） | 根拠 |
|---|---|---|
| 事業の質 | | |
| キャッシュフローの可視性 | | |
| 配当カバレッジ | | |
| バランスシートの強さ | | |
| 分配実績 | | |
| 増配余地 | | |
| バリュエーション | | |
| 景気循環性 | | |
| 減配リスク | | |
| ポートフォリオとの適合性 | | |

最終判断の前に、次の阻止ゲートを確認する：

- カバレッジのない分配が繰り返されている
- 重大な負債または借り換えリスク
- 事業の構造的な悪化
- ファンダメンタルズデータの不足
- 重大なガバナンスまたは誠実性への懸念

安全性、負債、悪化、誠実性のいずれかのゲートに不合格の場合、評価表より優先し、通常は `REJECT / YIELD TRAP` とする（既存ポジションで、利用可能なポートフォリオ情報から即時売却まで結論付けられない場合は `REDUCE`）。データ不足ゲートに該当する場合は `INSUFFICIENT DATA` とする。不合格ゲートをスコアで相殺してはならない。

次のうち、必ず1つだけを最終判断として返す：

- `CORE INCOME`
- `OPPORTUNISTIC INCOME`
- `WATCHLIST`
- `HOLD – DO NOT ADD`
- `REDUCE`
- `REJECT / YIELD TRAP`
- `INSUFFICIENT DATA`

最終判断では、想定されるポートフォリオ上の役割、主な理由、主なリスク、参入条件、検討対象となるポジションサイズのレンジ（万人に適するものではない）、買い増し条件、縮小／撤退基準、監視指標、確信度を示す。ポートフォリオ、税務、リスク許容度の情報が不十分な場合は、断定的で個別化された推奨を行ってはならない。

## 必須レポート形式

以下の見出しをそれぞれ1回だけ使用し、同じ分析を繰り返さない：

1. エグゼクティブサマリー
2. 最終判断とカテゴリー
3. 想定されるポートフォリオ上の役割
4. 事業と分配原資
5. 配当履歴と日程
6. 分配のカバレッジと安全性
7. バランスシートと借り換え
8. インカムの成長
9. バリュエーションと安全余裕
10. 税務と通貨
11. ポートフォリオとの適合性
12. シナリオ：基本、悪化、深刻
13. 減配リスク
14. 購入または買い増し条件
15. ポジション縮小または売却条件
16. 監視表
17. 一文での結論
18. 情報源とデータ品質

結果を `reports-jp/{company}-income-investment-{YYYYMMDD}.md` に保存する。ファイルシステムで安全に使える企業識別子を使用する。セクション2には評価表と阻止ゲートの結果、計算可能な場合はセクション11に月次インカム予定表、セクション18には情報源のタイトル、発行体／発行者、公開日、アクセス日、報告期間、URL、一次／二次の区分を含める。
