# 決算精読：一次資料の詳細分析

## 日本語版の共通実行ルール

- 株価、時価総額、財務数値、バリュエーションなどの通貨単位は、日本株では円（JPY）、米国株では米ドル（USD）を使用する。市場横断比較で換算する場合は、元の通貨を併記し、換算日と為替レートを明示する。
- レポートを保存・更新・検索する場合は、`reports/` ではなく `reports-jp/` 配下を使用する。
- データ取得・計算・検証には必要に応じて `tools/` の既存ツールを使用する。日本株では `python tools/jpstock_data.py quote {証券コード}` で株価、`financials` / `filings` でEDINETの財務・開示資料を取得し、重要数値は `tools/financial_rigor.py`、完成レポートは `tools/report_audit.py` で検証する。
- 競合・産業チェーンの調査では、日本・韓国・台湾・欧州・中国・米国など世界の関連企業を、上場市場や資料言語を理由に除外しない。ただし、特定の海外市場に固有のデータ取得手順、評価基準、通貨例は設けず、各社の公式IR・法定開示・取引所資料を優先する。

`$ARGUMENTS` の決算を精読・分析する。

**対応する入力形式**：`企業名 四半期`。例：`トヨタ 2026年3月期第1四半期`、`Apple 2026Q3`、`NVIDIA 最新`（デフォルトでは直近の決算を読み込む）

## 設計思想

多くのAI投資調査ツールは、二次情報（ニュース、調査レポートの要約、データサイト）に依存している。しかし、ウォーレン・バフェットと李録の中核能力は、**一次資料を読むこと**――年次報告書、四半期報告書、決算説明会の議事録を読むことにある。

二次情報の問題点：
- 選別されている――アナリストは、自身の見解に都合のよいデータを選択的に提示する
- タイムラグがある――他者が情報を消化し終えた頃には、アルファはすでに失われている
- 文脈が欠けている――「売上高が15%増加」という数字が、成長の質に関する経営陣の議論から切り離されている

このSkillは一次資料を直接読み解き、ウォーレン・バフェットと李録が実際に注目する内容に焦点を当てる。

## 実行手順

### 事前ステップ：資料の入手可能性評価

| 評価 | 特徴 | 影響 |
|------|------|------|
| A級 | 全文の原文を入手（10-K／年次報告書／決算説明会の議事録） | 全ステップを通常どおり実行 |
| B級 | 原文の一部または第三者の集計のみ入手 | 「一次資料ではない」と明記し、注記分析の比重を下げる |
| C級 | 報道とデータサイトの要約のみ | 中核となる財務データの変化に集中し、注記の深掘りは省略。「一次資料不足」と明記 |

### ステップ1：一次資料を取得する

Taskツールで複数のバックグラウンドAgentを起動し、以下の原資料を**並列**で取得する：

1. **決算原文**：企業のIRページ、日本株はEDINET／TDnet、米国株はSEC EDGARの10-K／10-Qから取得
2. **決算説明会の議事録／録音**：企業のIRページを優先し、必要に応じて信頼できる議事録サービスで補完する
3. **経営陣から株主への書簡**（年次報告書に含まれる場合）：全文を読む
4. **投資家説明会／アナリストデーの資料**（直近に開催された場合）

全文の原文を取得できない場合は、`skills/financial-data-jp.md` の基準に従い、日本株はEDINET／TDnet／企業IR、米国株はSEC EDGAR／企業IRを中心に、独立した第三者情報源で補完する。ただし、「決算原文ではなく、第三者による集計」と必ず明記し、重要データについて2つの情報源の誤差が1%を超える場合は印を付ける。競合企業の確認では各国の公式開示を参照するが、特定の海外市場専用ワークフローは設けない。

### ステップ2：中核となる財務データの抽出と検証

#### 2.1 売上高と利益計算書

| 指標 | 当期 | 前期 | 前年同期比の変化 | 経営陣のガイダンス | 達成状況 |
|------|------|------|---------|-----------|---------|

必須項目：
- 売上高合計、および事業別／地域別の売上高内訳
- 売上総利益、粗利率の変化
- 営業利益、営業利益率の変化（GAAPとNon-GAAPを区別）
- 純利益（非経常損益の影響に注意）
- EPS（基本EPS vs 希薄化後EPS）

#### 2.2 キャッシュフロー計算書（ウォーレン・バフェットが最も重視）

| 指標 | 当期 | 前期 | 変化 | 注目点 |
|------|------|------|------|--------|

必須項目：
- 営業キャッシュフローと純利益の比率（100%超が望ましく、80%未満は要警戒）
- 設備投資とその内訳（維持投資 vs 成長投資）
- フリーキャッシュフロー = 営業キャッシュフロー - 設備投資
- 自社株買いの金額、配当額
- 現金及び現金同等物の期末残高

#### 2.3 バランスシートの健全性

必須項目：
- 現金 + 短期投資 vs 有利子負債
- ネットキャッシュ／純負債の変化傾向
- 売掛金回転日数の変化（信用条件を緩和して売上高を押し上げていないか？）
- 棚卸資産回転日数の変化（滞留していないか？）
- のれんおよび無形資産の比率（減損リスクはないか？）

**データ検証**：`tools/financial_rigor.py` で重要データを検証する：

```bash
# 売上高と純利益のクロスチェック（2つ以上の情報源）
python3 tools/financial_rigor.py cross-validate \
  --metric "revenue" --values 108.3e9 107.9e9 --sources "企業の決算" "Yahoo Finance"

# 時価総額の検証
python3 tools/financial_rigor.py verify-market-cap \
  --price 101 --shares 1.488e9 --reported 1.44e11 --currency USD

# バリュエーション指標の再計算
python3 tools/financial_rigor.py verify-valuation \
  --price 101 --eps 9.6 --bvps 26.5 --fcf-per-share 10.2
```

### ステップ3：経営陣による説明の精読（MD&A）

ここは、ウォーレン・バフェットと李録が最も時間をかける部分である。数字を見るのではなく、**経営陣がどのように語っているかを聞く**。

#### 3.1 経営陣の語調分析

経営陣による説明／決算説明会での発言を段落ごとに読み、以下のシグナルを付ける：

| シグナルの種類 | 具体的な現れ方 | 例 |
|---------|---------|------|
| 🟢 **率直さのシグナル** | 問題を自ら認め、具体的な原因を示す | 「当四半期の利益率低下は、主にX分野への投資が想定を上回ったためです」 |
| 🟢 **明確さのシグナル** | 戦略の説明が具体的で、定量目標がある | 「今後12カ月でX事業の市場シェアを15%から20%に引き上げる計画です」 |
| 🔴 **曖昧さのシグナル** | 「私たちは信じている」、「長期的には」など、実質的な内容のない表現を多用 | 「私たちは将来に強い自信を持っています」 |
| 🔴 **論点転換のシグナル** | 直接的な質問を避け、別の話題へ移す | 利益率について問われた際に、売上高成長率の話へ切り替える |
| 🔴 **外部要因への責任転嫁** | 問題をすべてマクロ／業界／競合に帰する | 「マクロ環境の影響により...」 |

#### 3.2 公約の追跡

前回の決算／決算説明会から経営陣の具体的な公約を抽出し、当期の実績と比較する：

| 前回の公約 | 当期の達成状況 | 評価 |
|---------|------------|------|
| 「下半期に利益率をX%まで回復させる」 | 実績Y% | ✅達成 / ❌未達 / ⚠️一部達成 |

**段永平**：「経営陣が信頼できるかを見る最も簡単な方法は、以前言ったことを実行できたか確認することだ。」

#### 3.3 重要な質問の特定

決算説明会のQ&Aから、アナリストの最も鋭い質問と経営陣の回答の質を抽出する：

| アナリストの質問 | 経営陣の回答 | 回答の質（1～5） | 回避の有無 |
|-----------|-----------|:------------:|:-------:|

### ステップ4：注記と隠れた情報の発掘

決算の注記には、経営陣が簡単には見せたくない情報が隠されている：

#### 4.1 必ず確認する注記事項

- [ ] **関連当事者取引**：大株主／関連当事者との取引条件は公正か？
- [ ] **株式報酬**：オプション／RSUの希薄化効果はどの程度か？ 行使価格はいくらか？
- [ ] **偶発負債**：訴訟、保証、コミットメントなどのオフバランスリスク
- [ ] **会計方針の変更**：売上高の認識方法、減価償却期間などを変更していないか？
- [ ] **セグメント情報**：事業間の利益率の差。「良い事業が悪い事業を補助」していないか？
- [ ] **顧客／サプライヤー集中度**：上位5社の顧客／サプライヤー比率

#### 4.2 異常シグナルの検出

- [ ] 売掛金の成長率 > 売上高成長率（流通チャネルへの押し込み販売の可能性）
- [ ] 棚卸資産の成長率 > 売上高成長率（在庫滞留の可能性）
- [ ] 営業キャッシュフロー < 純利益、かつ差が拡大（利益の質に疑問）
- [ ] 資産計上される支出が突然増加（利益を良く見せている可能性）
- [ ] 非経常利益の比率が突然上昇

### ステップ5：過去データとの比較

#### 5.1 トレンド分析

当期の重要指標を、少なくとも4四半期（または3年分の年次報告書）の時系列に並べる：

| 指標 | Q-4 | Q-3 | Q-2 | Q-1 | 当期 | トレンド判断 |
|------|-----|-----|-----|-----|------|---------|

重点確認事項：
- 利益率は改善しているか、悪化しているか？
- 売上高成長率は加速しているか、減速しているか？
- キャッシュフローの質は向上しているか、低下しているか？
- 設備投資の強度は増加しているか、減少しているか？

#### 5.2 経営陣のガイダンスとの比較

| 指標 | 経営陣による従来のガイダンス | 実績 | 乖離 | 解釈 |
|------|--------------|---------|------|------|

### ステップ6：精読レポートの出力

#### レポート構成

```
1. 主要データの一覧（1ページの表）
2. 当期で最も重要な3つの変化（500字以内）
3. 経営陣の語調と公約の追跡
4. 注記に隠れた情報
5. 重要な質問（決算説明会Q&Aから厳選）
6. 投資仮説との関係（ポジションを保有している場合）
7. 結論：この決算によって何が変わったか？
```

#### 結論で必ず明確に答えること

1. **この決算は予想を上回ったか、予想どおりか、予想を下回ったか？**（「おおむね予想どおり」と述べた後、両論を大量に並べてはいけない）
2. **投資仮説への影響**：強化 / 影響なし / 弱化 / 崩壊
3. **次に注目すべきカタリストは何か？**
4. **すでに保有している場合、買い増し／保有継続／ポジション縮小のどれか？**

### ステップ7：レポートの保存

レポートを `reports-jp/{企業名}-earnings-{期間}.md` に保存する。例：`reports-jp/トヨタ-earnings-2026Q1.md`

### ステップ8：データの抜き取り検査（公開判定プロセス）

レポートの保存後にデータを抜き取り検査し、合格した場合のみ公開する：

```bash
# Step 1 — 抜き取り検査リストを抽出
python3 tools/report_audit.py extract \
  --report reports-jp/{企業名}-earnings-{期間}.md

# Step 2 — リストの各項目について信頼できる情報源から数値を取得（skills/financial-data-jp.mdを参照）

# Step 3 — 公開可否の判定を出力
python3 tools/report_audit.py verdict \
  --results '<填好的JSON>' \
  --report {报告文件名}
```

**【公開可】** すべて合格 → 公開。**【差し戻し】** 不合格あり → 修正後に再審査。

## 重要原則

- **要約ではなく原文を読む**：あらゆる手段を尽くして一次資料を取得する
- **絶対値ではなく変化を見る**：数字そのものよりトレンドが重要
- **内容だけでなく語調を聞く**：経営陣が何を言ったかと同じくらい、どのように言ったかが重要
- **本文だけでなく注記を調べる**：悪魔は細部に宿る
- **要約ではなく結論を出す**：精読の目的は判断を形成することであり、決算を言い換えることではない
