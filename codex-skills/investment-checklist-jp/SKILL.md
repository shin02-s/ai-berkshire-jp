# ウォーレン・バフェット流バリュー投資・購入前チェックリスト

## 日本語版の共通実行ルール

- 株価、時価総額、財務数値、バリュエーションなどの通貨単位は、日本株では円（JPY）、米国株では米ドル（USD）を使用する。市場横断比較で換算する場合は、元の通貨を併記し、換算日と為替レートを明示する。
- レポートを保存・更新・検索する場合は、`reports/` ではなく `reports-jp/` 配下を使用する。
- データ取得・計算・検証には必要に応じて `tools/` の既存ツールを使用する。日本株では `python tools/jpstock_data.py quote {証券コード}` で株価、`financials` / `filings` でEDINETの財務・開示資料を取得し、重要数値は `tools/financial_rigor.py`、完成レポートは `tools/report_audit.py` で検証する。
- 競合・産業チェーンの調査では、日本・韓国・台湾・欧州・中国・米国など世界の関連企業を、上場市場や資料言語を理由に除外しない。ただし、特定の海外市場に固有のデータ取得手順、評価基準、通貨例は設けず、各社の公式IR・法定開示・取引所資料を優先する。

`$ARGUMENTS` について、ウォーレン・バフェット流バリュー投資の購入前チェックリスト分析を実行する。

**対応する入力形式**：1社または複数社。カンマ／読点／スペースで区切る。例：`トヨタ, ソニー, NVIDIA` または `NVDA AAPL MSFT`

## 実行手順

### ステップ1：入力を解析し、分析対象の全企業を特定する

`$ARGUMENTS` からすべての企業名／コードを抽出する。各社について以下を特定する：
- 正式な企業名、株式コード、上場取引所
- 未上場企業の場合は「未上場」と表示し、簡潔な説明（間接的な投資手段があるか）を記載して、完全版チェックリストを省略

### ステップ1.5：AI調査バイアスへの警告

各社の「情報の豊富さ」をA／B／Cで簡易評価し、レポートに明記する：

| 評価 | 判断基準 | チェックリストへの影響 |
|------|---------|-----------------|
| A級 | 上場から長く、データが豊富 | 通常どおり実行するが、「コンセンサスの罠」に注意。すべての指標が明確に見えても、本当に確実とは限らない |
| B級 | データが限られ、推計が必要 | 各推計指標に確信度を付け、「優れた事業」の判断ではデータの信頼性を加味 |
| C級 | 情報が極めて少ない | 6つの関門の表を無理に埋めず、「データ不足で判断不能」と正直に明記し、検証可能な中核問題に集中 |

**中核原則**：チェックリストの目的は、**悪い選択を排除すること**。C級企業では、「データ不足」は「不合格」でも「合格」でもない。AIが表を埋められないことを理由に否決せず、「グレーゾーン。一次情報の追加が必要」と正直に記載する。

段永平はこう述べている。「理解できない」には2種類ある。事業が複雑すぎて本当に理解できない場合と、まだ理解するための時間をかけていない場合である。AI調査の限界は、「資料が少ない」と「理解できない」を混同しやすいことにある。

### ステップ2：データを並列収集する

Taskツールを使用し、**各企業**について独立したバックグラウンドAgentを起動してデータを収集する（全企業を同時に並列起動）。各Agentは以下を収集する：

1. **収益力**：自己資本利益率（5～10年の傾向）、粗利率、純利益率、フリーキャッシュフロー
2. **バリュエーションデータ**：現在の株価、時価総額、PER（TTM）、予想PER、PBR、配当利回り
3. **成長傾向**：直近3年間の売上高／利益成長率
4. **財務の健全性**：負債水準、設備投資需要、現金準備、ネットキャッシュ／純負債
5. **競争環境**：市場シェア、主な競合、市場シェアの変化傾向
6. **経済的な堀の証拠**：ブランド／スイッチングコスト／ネットワーク効果／規模の経済／技術的参入障壁の具体的な証拠
7. **経営陣の実績**：CEOの経歴、重要な意思決定、持株、資本配分の実績
8. **最新動向**：直近6カ月の重要イベント（業績、M&A、規制、経営陣の変更など）

### ステップ3：各社について6つの関門を順に確認する

上場企業ごとに、6つの関門を順番に確認する：

---

#### 第1関門：この事業を理解できるか（能力の輪）

必ず答える：
- [ ] この企業が何で利益を得ているか、一文で説明できるか？
- [ ] 10年後も、おそらくどのような事業をしているか？
- [ ] 成否を決める重要な変数は何か？
- [ ] この業界への理解は詳細調査に基づくか、伝聞に基づくか？

**評価基準**（★1～5）：
- ★★★★★：ビジネスモデルが極めて単純明快で、10年後の確実性が高い（例：日用品や飲料など、需要と収益構造を説明しやすい事業）
- ★★★★☆：モデルは明確だが技術的な参入障壁があり、理解に一定の専門知識が必要
- ★★★☆☆：モデルは理解できるが、10年後の確実性は高くなく、業界の変化が速い
- ★★☆☆☆：事業ラインが複雑、または業界が激変しており、将来を予測しにくい
- ★☆☆☆☆：能力の輪から完全に外れている

**強制否決**：利益の仕組みすら説明できない場合は、直ちに「能力の輪の外にあり、分析しない」と表示する。

---

#### 第2関門：これは優れた事業か（経済的特性）

データで説明し、**重要指標は必ずツールで正確に計算する**：

```bash
python3 tools/financial_rigor.py verify-valuation \
  --price {株価} --eps {EPS} --bvps {1株当たり純資産} --fcf-per-share {1株当たりFCF} --dividend {1株当たり配当}
```

| 指標 | 対象企業の数値 | 参考基準 | 判断 |
|------|-----------|---------|------|
| 自己資本利益率（5年平均） | | 15%超は優良、20%超は卓越 | |
| 粗利率 | | 40%超は価格決定力を示唆 | |
| フリーキャッシュフロー | | 継続的にプラス、純利益とおおむね一致 | |
| 設備投資の強度 | | 資産の軽い事業は資産の重い事業より優位 | |
| 負債水準 | | 有利子負債／純利益が3年未満 | |

**評価基準**（★1～5）：
- ★★★★★：自己資本利益率25%超、高い粗利率、強いフリーキャッシュフロー、資産が軽い、負債が少ない（すべて合格）
- ★★★★☆：4項目合格
- ★★★☆☆：3項目合格
- ★★☆☆☆：2項目合格、または傾向が悪化
- ★☆☆☆☆：大半が不合格、またはフリーキャッシュフローが継続的にマイナス

---

#### 第3関門：経済的な堀は十分に深いか（競争優位性）

項目ごとに確認する：

| 経済的な堀の種類 | 有無 | 具体的な証拠 | 広がっているか、狭まっているか？ |
|-----------|---------|---------|--------------|
| ブランド／価格決定力 | | | |
| スイッチングコスト | | | |
| ネットワーク効果 | | | |
| コスト／規模の優位性 | | | |
| 技術／特許の参入障壁 | | | |

追加検証：競合に十分な資本を与えた場合、この事業を再現できるか？

**評価基準**（★1～5）：
- ★★★★★：複数の経済的な堀が重なり、さらに広がっている
- ★★★★☆：強い経済的な堀が少なくとも1つあり、安定している
- ★★★☆☆：経済的な堀はあるが十分に深くない、または傾向が不明
- ★★☆☆☆：経済的な堀が侵食されている
- ★☆☆☆☆：明確な経済的な堀がない

#### 第4関門：経営陣は信頼できるか（人の要因）

| 確認項目 | 評価 |
|--------|------|
| 誠実さ（公約 vs 実績） | |
| 資本配分能力（自社株買い／配当／M&Aの実績） | |
| 株主利益への志向（持株、報酬） | |
| オーナーとしての意識（創業者 vs プロ経営者） | |
| コーポレートガバナンス（関連当事者取引、のれん、監査） | |
| CEOが退任しても通常どおり運営できるか？ | |

**評価基準**（★1～5）：
- ★★★★★：創業者が指揮を執り、資本配分が卓越し、利害が完全に一致
- ★★★★☆：経営陣は優秀だが、小さな欠点がある
- ★★★☆☆：経営陣は合格水準だが、ガバナンス上の懸念がある
- ★★☆☆☆：誠実性またはガバナンスに問題がある
- ★☆☆☆☆：重大な誠実性の問題（→強制否決）

### ステップ4：鏡のテスト

各社について鏡のテストの文章を書く：

> 「私は___元で___社を買う。その理由は：
> 1. この事業の本質は___であり、私は理解している。
> 2. 経済的な堀は___であり、広がっている／狭まっている。
> 3. 経営陣は___であり、信頼できる／信頼できない。
> 4. 現在の価格は本源的価値の___%に相当し、十分な安全余裕がある／ない。
> 5. 私の判断が誤っていても、下方リスクは制御可能／制御不能である。その理由は___。」

**5文を完成できない = 買わない。** 「合格」または「不合格」を明記する。

### ステップ5：迅速な否決リスト

各社について項目ごとに確認し、1つでも該当すれば直ちに「否決」とする：

- [ ] この企業がどのように利益を得ているか説明できない

## 出力形式の要件

1. 各社を独立した章にし、6関門の評価表 + 主要データ表 + 重要リスク（3～5項目）+ 鏡のテスト + 明確な結論を含める
2. 複数社の場合は末尾に全体比較表を付ける
3. すべての評価で★記号（★1～5）を使用し、半星は使わない
4. データには必ず情報源の時点を明記し、推定値には「推定」と記載
5. 文末に、ウォーレン・バフェットの言葉「投資の第1ルールは、損をしないこと」に呼応する結びを付ける
6. 文体：直接的で鋭く、無駄を省く。ウォーレン・バフェット／チャーリー・マンガー／段永平の言葉を織り交ぜてコメントする

## 重要原則

- **逃してもよいが、誤ってはならない**：チェックリストの目的は悪い選択を排除することであり、最良の企業を見つけることではない
- **能力の輪に正直であること**：理解できない場合は、理解できないと言う。無理に分析しない
- **安全余裕は生命線**：優れた企業でも、高く買えば損失を出す
- **鏡のテストを省略しない**：理由を明確に説明できなければ買わない。例外はない
