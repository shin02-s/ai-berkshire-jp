# 日本株の買付前チェックリスト

`$ARGUMENTS` の一社または複数社を、買付前の六つの門で確認する。会社名・東証コードを読点、空白等で区切った入力を受け付ける。

## 第1段階：入力を解析する

会社名、証券コード、東証市場区分を確定する。対象は東証内国普通株。ETF、REIT、外国株、未上場会社は対象外とし、理由を示して完全チェックを止める。

### 情報充実度

| 等級 | 条件 | 影響 |
|---|---|---|
| A | 長期の一次資料が揃う | 通常実行。ただし市場共識に引きずられない |
| B | 一部を推定する必要 | 推定ごとに確信度を付ける |
| C | 一次資料または履歴が不足 | 無理に埋めず「灰色・追加情報必要」 |

資料が少ないことと、事業が理解不能なことを混同しない。Cは自動不合格でも自動合格でもない。

---

## 第2段階：並行データ収集

複数企業では一社につき独立したAgentを同時起動し、次を構造化して集める。利用できない場合は順番に実行する。

1. ROE、粗利、営業利益率、FCFの5～10年推移。
2. 株価、時価総額、PER、PBR、配当利回り。
3. 3年の売上・利益・一株利益・株式数の変化。
4. 負債、利払い、設備投資、現預金、純有利子負債。
5. シェア、主要競合、顧客・供給者、変化方向。
6. ブランド、切替費用、規模、技術、ネットワーク等の具体的証拠。
7. 経営者、主要意思決定、持株、報酬、資本配分。
8. 直近6か月の決算、M&A、規制、経営交代、不祥事。

情報源はEDINET、会社IR、TDnet、JPXを優先し、`skills/financial-data-jp.md` に従う。

## 第3段階：六つの門

### 第1門：この事業を理解できるか

- 一文で何により稼ぐか説明できるか。
- 10年後も何を売っている可能性が高いか。
- 成否を決める3～5の変数は何か。
- 理解は一次資料の研究か、借り物の物語か。

5点：単純で収益構造と10年後が明瞭。4点：明瞭だが専門知識が必要。3点：理解可能だが変化が速い。2点：複雑で予測困難。1点：理解不能。

稼ぎ方を説明できなければ「能力圏外」とし、その先の総合点で救済しない。

### 第2門：良い事業か

```bash
python tools/financial_rigor.py --locale ja verify-valuation --price {株価} --eps {EPS} --bvps {BPS} --fcf-per-share {1株FCF} --dividend {年間配当}
```

| 指標 | 値 | 観察基準 | 判断 |
|---|---:|---|---|
| 5年平均ROE | | 15%超を一つの目安。財務レバレッジを分解 | |
| 粗利率 | | 水準より同業差と方向 | |
| FCF | | 継続性、利益との整合 | |
| 設備投資強度 | | 維持投資と成長投資を分離 | |
| 負債 | | 金利・満期・景気悪化耐性 | |

5点：高い資本効率、強いCF、低い財務リスクが全部成立。4点：一つ軽微な不足。3点：平均的。2点：複数悪化。1点：FCFまたは財務に重大問題。

### 第3門：競争優位は深いか

| 種類 | 有無 | 証拠 | 拡大／維持／縮小 |
|---|---|---|---|
| ブランド・価格決定力 | | | |
| 切替費用 | | | |
| ネットワーク | | | |
| 費用・規模 | | | |
| 技術・特許・認証 | | | |

「十分な資本を持つ競合が3～5年で再現できるか」を問う。5点は複数優位が拡大、4点は強い優位が安定、3点は存在するが不確実、2点は侵食、1点は証拠なし。

### 第4門：経営を信頼できるか

| 項目 | 評価 |
|---|---|
| 目標と実績、都合の悪い説明 | |
| 投資、買収、売却、配当、DOE、自己株式取得・消却 | |
| 持株、報酬、希薄化 | |
| 政策保有株、持合い、余剰現金 | |
| 親子上場、支配株主、関連当事者、少数株主保護 | |
| 経営者が去った後の再現性 | |

誠実性に重大な問題があれば1点かつ硬い否決。能力と少数株主への公正さを分ける。

### 第5門：価格に安全余地があるか

| 指標 | 値 | 自社過去・同業 | 判断 |
|---|---:|---:|---|
| PER | | | |
| 予想PER | | | |
| PBR | | | |
| 配当利回り | | | |
| FCF利回り | | | |

```bash
python tools/financial_rigor.py --locale ja three-scenario --price {株価} --eps {EPS} --shares {株式数_億株} --growth {楽観} {基準} {保守} --pe {楽観PER} {基準PER} {保守PER} --currency JPY
```

三情景の価値範囲、判断違いの下落余地、株価半減時に仮説が健全なら追加できるかを答える。5点は大きい安全余地、4点は十分、3点はおおむね合理的、2点は不足、1点は成功を過度に織り込む。

### 第6門：比率と決定規律

- 取り残される恐怖や他人の推奨が主因ではないか。
- 市場が5年閉じても保有できるか。
- 200字以内で買付理由を書けるか。
- 現金、既存保有株、他候補より機会費用が優れるか。
- 最大損失が生活・組合に与える影響を許容できるか。

## 第4段階：鏡テスト

```text
私は {価格}円で{会社名}を検討する。理由は、
1. 事業の本質は___で、利益の仕組みを理解している。
2. 競争優位は___で、拡大／維持／縮小している。
3. 経営は___で、信頼できる／できない根拠は___。
4. 現在価格は価値範囲の___で、安全余地はある／ない。
5. 私が誤っても下落が制御可能／不能なのは___。
```

5文を具体的に埋められなければ不通過。

## 第5段階：快速否決

- [ ] 稼ぎ方を説明できない。
- [ ] 3年連続FCFが負で改善経路がない。
- [ ] 経営の誠実性に重大な問題がある。
- [ ] 競争優位が不可逆に侵食されている。
- [ ] より高値で買う相手だけが利益源である。
- [ ] 投資が全損した場合に耐えられない。
- [ ] 買付理由が人気または直近上昇に依存する。
- [ ] 200字以内で理由を書けない。
- [ ] 支配株主との重大な利益相反が未解消。
- [ ] 重要数値を一次資料で確認できない。

一つでも重大に該当すれば、星の合計で相殺しない。

## 第6段階：複数社の比較

| 会社 | 結論 | 能力圏 | 事業 | 優位 | 経営 | 安全余地 | 決定規律 | 核心理由 |
|---|---|---|---|---|---|---|---|---|

各門は1～5個の `★` で表し、半星は使わない。

## 第7段階：結論、保存、監査

- `通過`：深掘りへ進める。
- `条件付き通過`：不足情報または価格条件がある。
- `灰色`：核心争点を確認できない。
- `不通過`：硬い否決条件がある。

各社に六門表、核心数値、3～5リスク、鏡テスト、明確な結論を置く。複数社なら最後に比較表を置く。

`reports/{会社名または複数社}-investment-checklist-{YYYYMMDD}.md` へ保存し、既存ファイルがあれば無断で上書きせず日付・枝番を付ける。

```bash
python tools/report_audit.py --locale ja extract --report {レポートパス} --market jp
python tools/report_audit.py --locale ja verdict --results '<照合済みJSON>' --report {レポート名} --market jp
```

監査不合格は草稿とし、数値を直して再実行する。

## 原則

見逃しよりも理解しない買付を避ける。安全余地は良い会社という物語で代替できない。鏡テストを省かず、データ不足を合格へ読み替えない。
