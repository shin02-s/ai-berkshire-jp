# 日本株の買付前チェックリスト

## 一票否決

次のいずれかが重大かつ未解消なら、評価の安さにかかわらず見送る。

- 事業の利益発生構造を一文で説明できない。
- 開示の信頼性、経営者の誠実性、関連当事者取引に重大な疑義がある。
- 継続企業、過大な負債、資金繰り、希薄化に現実的な危険がある。
- 支配株主との利益相反や少数株主保護の欠陥が放置されている。
- 重要数値を一次資料で確認できない。

## 採点項目

1. **能力圏**：顧客、収益源、費用、成長要因、失敗条件を説明できるか。
2. **事業品質**：反復収益、価格決定力、資本集約度、景気感応度、顧客集中。
3. **競争優位**：根拠、持続期間、過去5年の拡大・縮小、破壊要因。
4. **経営と資本配分**：投資、買収、売却、配当、DOE、自己株式取得、消却、負債。
5. **ガバナンス**：親子上場、持合い、政策保有株、支配株主、取締役会、報酬。
6. **財務品質**：利益と営業CF、運転資本、減損、引当、オフバランス項目。
7. **安全余地**：円建て現在価値、三情景、期待収益率、下落耐性。
8. **機会費用**：同じ資金を現金または既存保有株へ置く場合より優れるか。


## 判定

「通過」「条件付き通過」「灰色」「不通過」のいずれかを選び、未確認事項、買える価格帯、次に確認する開示、仮説撤回条件を記載する。情報源は `skills/financial-data-jp.md` に従う。
