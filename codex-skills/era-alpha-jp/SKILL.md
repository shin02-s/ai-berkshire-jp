# 時代のアルファ・ハンター：高成長の中核資産を特定・検証・保有するフレームワーク

## 日本語版の共通実行ルール

- 株価、時価総額、財務数値、バリュエーションなどの通貨単位は、日本株では円（JPY）、米国株では米ドル（USD）を使用する。市場横断比較で換算する場合は、元の通貨を併記し、換算日と為替レートを明示する。
- レポートを保存・更新・検索する場合は、`reports/` ではなく `reports-jp/` 配下を使用する。
- データ取得・計算・検証には必要に応じて `tools/` の既存ツールを使用する。日本株では `python tools/jpstock_data.py quote {証券コード}` で株価、`financials` / `filings` でEDINETの財務・開示資料を取得し、重要数値は `tools/financial_rigor.py`、完成レポートは `tools/report_audit.py` で検証する。
- 競合・産業チェーンの調査では、日本・韓国・台湾・欧州・中国・米国など世界の関連企業を、上場市場や資料言語を理由に除外しない。ただし、特定の海外市場に固有のデータ取得手順、評価基準、通貨例は設けず、各社の公式IR・法定開示・取引所資料を優先する。

`$ARGUMENTS` の業界／テーマについて「時代のアルファ・4ステップ法」を実行する：業界の認識マップを構築 → 中核的な問いを自問 → 全方位から検証 → 転換点まで保有。現在の最重要高成長業界から、真に価格決定力と参入障壁を持ち、同業他社を持続的に上回れるアルファ企業を見つけ、参入と撤退の規律を示すことを目的とする。

## 方法論の由来と本質

プロ投資家の4ステップ実践マニュアルを基にしている。本質を一文で言えば、**運や感情ではなく、理解の上に富を築くこと**。原型となる4ステップ（1年分の決算を読んでマップを構築 → 中核的な高成長業界と中核アルファを自問 → 決算 + 調査 + 業界 + マクロを全面的に検証してから参入 → ファンダメンタルズの転換点まで徹底保有）はプロの修練過程である。このスキルでは、実行可能な手順にするため3つの修正を組み込んでいる：

1. **修正1（対象範囲の絞り込み）**：全業界を網羅せず、指定分野の中核工程2～3個に集中して徹底的に掘り下げる。1,000社を知るより、本当に理解した3～5社のほうがよい。
2. **修正2（高頻度データのクロスチェック）**：決算は3カ月前の健康診断書である。業界の高頻度データ（週次／月次の出荷量、価格、受注、設置量、普及率）をリアルタイムの体温計として使い、必ず補正する。
3. **修正3（バリュエーションの基準点）**：長期的には「高いものがさらに高くなる」こともあるが、PERが過去平均を3標準偏差上回る時点で参入すると、長期にわたり時間を失う可能性がある。妥当または割安なときに集中投資し、明白なバブルではポジション縮小、転換点を確認したら全売却する。目を閉じて買わない。

既存スキルとの役割分担：
- `industry-research` は産業チェーン全体の俯瞰的な断面分析、`industry-funnel` は市場全体のファネル型スクリーニングに重点を置く
- `era-alpha` は「時代を代表する高成長の主要テーマ」におけるアルファの特定 + 成長の持続可能性の検証 + 保有／撤退規律に重点を置く。対象をより狭くし、検証を深く行い、明確な転換点の一覧を提示する

## ステップ1：業界の認識マップ（原型の「365本の決算を読む」を絞り込んだ版）

対象分野の産業チェーン認識マップを作成し、各工程について答える：

1. この工程はどの段階にあるか？（導入期／成長期／成熟期／衰退期。普及率と成長率で位置付ける）
2. ビジネスモデルと収益の仕組みは？（粗利率、費用率、キャッシュフローと利益の整合性）
3. 競争環境は？（CR3、価格決定力を誰が持つか、参入障壁は技術／規模／エコシステム／許認可のどれか）
4. 各工程のアルファ候補は誰か？（売上高成長率、自己資本利益率の傾向、市場シェアの変化という3つの観点で選別）

**情報源の要件**：目論見書、年次報告書／四半期報告書、決算説明会の議事録などの一次資料を中心とし、証券会社の見解は手掛かりとしてのみ使い、結論には使わない。投資候補はユーザーが指定した市場から選び、競合・産業チェーンの把握では日本・韓国・台湾・欧州・中国・米国の上場・未上場企業を、資料を探しにくいことを理由に漏らさない。

**成果物**：産業チェーン工程表（工程 | 段階 | 競争環境 | アルファ候補 | 一文での理由）を作成し、最も深掘りする価値がある中核工程を2～3個選ぶ（修正1）。

## ステップ2：中核的な問いを自問する（他人の意見を聞かない）

ステップ1のデータを使って答える。「市場コンセンサス」や「機関投資家の見解」を論拠として引用してはならない：

1. **現在、この分野で最も中核的かつ最も成長が速い工程はどこか？** データで説明する：成長率、普及率、受注の可視性。
2. **その工程の中核アルファは誰か？** 基準：価格決定力（粗利率が同業他社より高く、安定または上昇）、参入障壁（競合が3年以内に追い付けないものは何か）、成長の質（売上高の成長にキャッシュフローの成長を伴い、信用販売で作った成長ではない）。
3. **なぜ2番手ではなく、その企業なのか？** アルファとベータの違いを一文で明確に説明できなければ、理解できていない。

**成果物**：中核アルファ1～3社 + 明確な「なぜその企業なのか」という論証。

## ステップ3：全方位からの検証（決算 + 高頻度データのクロスチェック）

各中核アルファについて、成長の持続可能性に関する5つの問いを検証する。すべての観点が一貫して「高成長は持続可能」と示して初めて、理解したとみなす：

| 観点 | 検証内容 |
|------|---------|
| 決算 | 直近4～8四半期の売上高／利益の成長率推移、粗利率の方向性、契約負債／棚卸資産／建設仮勘定などの先行指標 |
| 高頻度データ（修正2） | 当該工程の週次／月次リアルタイム指標（出荷量、価格、入札、トラフィック、トークン呼び出し量など）が決算の傾向と一致しているか |
| 業界追跡 | 政策の方向性、技術経路が覆されるリスク、供給側の増産ペース（供給過剰は成長株にとって最大の脅威） |
| 競争環境 | 市場シェアの変化方向、新規参入の脅威、顧客集中度と交渉力 |
| マクロ | 金利環境、設備投資サイクル上の位置、地政学／規制上の変数 |

**いずれか1つの観点で矛盾するシグナルが出た場合、必ず明記し、曖昧に処理してはならない。**

## ステップ4：バリュエーションの基準点と参入（修正3。「株価を見ない」の代替）

1. 現在のPER／PSRは、自社の過去のどの分位にあるか？ 過去平均 + 3標準偏差を超えているか？
2. バリュエーションと成長率は釣り合っているか？（PEGの観点：高成長は高いバリュエーションを吸収できるが、何年必要かを明確に計算する）
3. 結論は次の3択：**割安／妥当で集中投資による参入が可能**、**割高だが成長で吸収可能なため保有または分割購入**、**明白なバブルのため観察のみで買わない**。
4. 参入方法を提案する：一括／分割／どの水準までの調整を待つか。

## ステップ5：保有規律と転換点一覧

**保有規律**：ファンダメンタルズがすべて正常である限り（成長率が鈍化していない、競争環境が悪化していない、普及率が引き続き上昇している、マクロが逆転していない）、株価変動はノイズである。何があっても安易に手放してはならない。

**転換点一覧**（各アルファについて必ず作成し、すべて観察可能かつ反証可能にする）：

| 階層 | 転換点シグナルの例 |
|------|------------|
| マクロの転換点 | 金融政策の転換、設備投資サイクルのピークアウトを示すシグナル |
| 業界の転換点 | 供給過剰による価格崩壊、技術経路の破壊的変化、普及率の頭打ち、政策の逆転 |
| 企業の転換点 | 中核経営陣の退任、粗利率が2四半期連続で低下、市場シェアの侵食、契約負債がマイナス成長へ転換 |

各シグナルについて、**どのデータを、どの頻度で観察するか**を明記し、「転換点」を感覚からチェックリストへ変える。

## 実行方法

1. データ量が多い場合は、産業チェーンの工程別に調査Agentを並列で起動する（1工程につき1Agent）。最新の決算と高頻度データをオンラインで取得し、構造化された事実（データ + 出典）を返し、意見は返さないよう求める。
2. メインスレッドでステップ1から5までを統合し、レポートを作成する。
3. `financial-data` スキルのクロスチェック基準に従う。重要な数値（成長率、粗利率、バリュエーション分位）には必ずデータの基準日を明記する。

## レポート構成

```
1. 業界の認識マップ（工程表 + 中核工程の選定理由）
2. 中核的な問いへの回答（最重要高成長工程 + 中核アルファ + なぜその企業か）
3. 成長の持続可能性検証（5つの観点を項目別に確認 + 矛盾するシグナルを明示）
4. バリュエーションの基準点と参入提案
5. 保有規律と転換点一覧（観察可能、反証可能）
6. 本レポートが誤っている可能性（自己反証を3項目以上）
```

文体の要件：データ密度を優先し、確かなデータをすべて残し、足場としての冗長な言葉は削る。日本語のみで表現する。投資家の名前を掲げず、分析の観点で各章に名前を付ける。
