# 日本株の総合投資研究：4つの価値投資視点による8段階分析

## 調査フレームワーク

`$ARGUMENTS` の会社について、良い事業か、長期価値を増やせるか、経営者が合理的か、現在価格に安全余地があるかを分けて検証する。対象は東証内国普通株に限定する。

## 事前段階：AI調査バイアス

情報充実度をA・B・Cで評価し、レポート冒頭へ記載する。

- A：情報が多いため市場コンセンサスの再生産を警戒する。
- B：推定値と確認済み数値を分ける。
- C：網羅性を捨て、事業の本質と重大な不明点へ集中する。

次を自問する。

- 自分の分析は市場見解と同じではないか。
- 反対意見を弱く書いていないか。
- 資料の多さを事業の確実性と誤認していないか。
- 数字の欠損を推測で埋めていないか。

## ステップ1：データ収集

`skills/financial-data-jp.md` を使い、調査日、証券コード、市場区分、会計基準、決算期を固定する。

1. EDINETの有価証券報告書、半期報告書、臨時報告書。
2. 会社IRとTDnetの決算短信、説明資料、適時開示。
3. JPXの上場会社情報、株価、株式数。
4. コーポレートガバナンス報告書、株主総会資料、中期計画。
5. 官公庁、業界団体、顧客・供給者の一次資料。

重要数値を一次資料と別経路で照合する。独立した第二経路がなければ低信頼と表示する。

```bash
python tools/jpstock_data.py quote {証券コード}
python tools/jpstock_data.py financials {証券コード}
python tools/jpstock_data.py filings {証券コード} --years 5
python tools/financial_rigor.py --locale ja verify-market-cap --price {株価} --shares {株式数} --reported {時価総額} --currency JPY
python tools/financial_rigor.py --locale ja cross-validate --field {項目} --values '{"一次資料":0,"別経路":0}' --unit 百万円
python tools/financial_rigor.py --locale ja verify-valuation --price {株価} --eps {EPS} --bvps {BPS} --dividend {配当}
```

## ステップ2：事業の本質

段永平の「良い事業」の観点を使い、本人を装わず原則として適用する。

1. 誰が、何に、なぜ払い、何が反復するかを一文で説明する。
2. 売上をセグメント、地域、顧客、数量、単価、継続・一括へ分解する。
3. 原価、固定費、運転資本、設備投資、研究開発を示す。
4. 事業のフライホイールと制約条件を描く。
5. 成長が売上だけでなく増分利益とFCFへ届くか確認する。
6. 10年後にも顧客の問題が存在するかを考える。

出力は事業モデル図、利益を動かす2〜3変数、理解できない部分、1〜5評価とする。

## ステップ3：競争優位

競争優位を次の要素へ分け、証拠、5年変化、破壊条件を示す。

| 要素 | 確認内容 |
|---|---|
| ブランド・価格 | 値上げ、数量、解約、価格差 |
| 切替費用 | 契約、データ、教育、業務組込み |
| ネットワーク | 参加者増加が他者価値を高めるか |
| 規模・コスト | 調達、設備、物流、販売、固定費 |
| 技術・認証 | 模倣時間、知財、品質、顧客承認 |
| 希少資産・規制 | 権利、立地、許認可、供給枠 |

「業界首位」は競争優位の証拠ではない。首位が利益と再投資能力へ変わる経路を書く。

## ステップ4：逆向き思考とリスク

1. 賢い非保有者が買わない理由を書く。
2. 事業、財務、競争、規制、技術、品質、災害、サイバーの失敗経路を列挙する。
3. 各リスクへ確率、影響、先行指標、緩和策を付ける。
4. 最も起こりやすい分析ミスを一つ選ぶ。
5. 仮説を即時撤回する条件を定義する。

離散リスクを根拠なく割引率へ上乗せせず、シナリオまたは確率で扱う。

## ステップ5：経営陣と資本配分

少なくとも5年の意思決定履歴で評価する。

- 設備投資、研究開発、採用、買収、売却。
- 配当、DOE、自己株式取得、消却、株主優待。
- 増資、転換証券、負債、余剰現金。
- 政策保有株、持合い、非事業資産の縮減。
- 中期計画の目標と実績、未達説明。
- 報酬、株式保有、後継計画、取締役会。

親子上場、支配株主、関連当事者取引がある場合、能力と少数株主への公正さを別に採点する。

## ステップ6：業界と長期構造変化

1. 需要を動かす人口、制度、技術、更新周期、顧客投資を確認する。
2. 産業チェーンと利益プールを描く。
3. 供給者、顧客、競合、代替の交渉力を示す。
4. 業界成長と対象企業の価値獲得を分ける。
5. 循環要因と5年以上の構造要因を分ける。
6. 海外企業は競争・顧客・供給網の説明に限定する。

## ステップ7：円建て評価と安全余地

### 三情景評価

```bash
python tools/financial_rigor.py --locale ja three-scenario --price {株価} --eps {EPS} --shares {株式数_億株} --growth {強気} {基準} {弱気} --pe {強気PER} {基準PER} {弱気PER} --currency JPY
```

成長率、利益率、株式数、終値倍率、配当・自己株式取得を明示する。過去倍率は事業構成と金利環境の違いを考慮する。

### 10年終価・IRR

調査日の円無リスク金利を公式資料から確認する。

```bash
python tools/terminal_value.py --locale ja audit --currency JPY --rf {無リスク金利} --r {資本コスト} --roic {定常ROIC} --g {弱気},{基準},{強気}
python tools/terminal_value.py --locale ja pe --roic {定常ROIC} --g {永続成長率} --r {資本コスト}
python tools/terminal_value.py --locale ja irr --profit {終値年利益} --mcap {現在時価総額} --pe {終値PER} --years 10 --payout {配当等}
```

`r > g`、最低スプレッド、同一通貨、株式数、利益口径を確認する。監査不合格の終価をレポートへ採用しない。

### 逆算

現在価格を正当化する売上、利益率、ROIC、成長期間を逆算し、会社の過去実績と比較する。
