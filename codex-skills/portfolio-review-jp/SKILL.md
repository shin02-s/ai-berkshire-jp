# 日本株ポートフォリオ・レビュー

## 入力

ユーザーが渡した保有銘柄、比率、取得価格、現金比率だけを使う。株数や金額が機密なら比率ベースで処理し、推測しない。

## 手順

1. 基準日を固定し、各銘柄の最新開示と株価を確認する。
2. 各銘柄の投資仮説、撤回条件、情報信頼度、現在評価を一行で更新する。
3. 業種、顧客、景気、為替、金利、原材料、規制、災害の共通リスクを集計する。
4. 表面的な銘柄数ではなく、利益要因の集中を確認する。
5. 親子上場、持合い、政策保有株、支配株主等のガバナンス集中も確認する。
6. 各銘柄の円建て期待収益を同じ期間・同じ仮定で比較する。
7. 追加、維持、縮小、売却、監視へ分類し、機会費用を示す。

## 計算

```bash
python tools/financial_rigor.py --locale ja verify-valuation --price {株価} --eps {EPS} --bvps {BPS}
python tools/financial_rigor.py --locale ja three-scenario --price {株価} --eps {EPS} --shares {株式数_億株} --growth {強気} {基準} {弱気} --pe {強気PE} {基準PE} {弱気PE} --currency JPY
```

## 出力

ポートフォリオ全体の判定、保有別レビュー、共通リスク、集中度、期待収益順位、行動候補、次回確認日を出す。売買命令ではなく、判断条件として表現する。未提供の個人情報や口座情報を生成・保存しない。
