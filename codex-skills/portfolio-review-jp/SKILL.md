# ポートフォリオ管理：「企業を調査する」から「ポートフォリオを管理する」へ

## 日本語版の共通実行ルール

- 株価、時価総額、財務数値、バリュエーションなどの通貨単位は、日本株では円（JPY）、米国株では米ドル（USD）を使用する。市場横断比較で換算する場合は、元の通貨を併記し、換算日と為替レートを明示する。
- レポートを保存・更新・検索する場合は、`reports/` ではなく `reports-jp/` 配下を使用する。
- データ取得・計算・検証には必要に応じて `tools/` の既存ツールを使用する。日本株では `python tools/jpstock_data.py quote {証券コード}` で株価、`financials` / `filings` でEDINETの財務・開示資料を取得し、重要数値は `tools/financial_rigor.py`、完成レポートは `tools/report_audit.py` で検証する。
- 競合・産業チェーンの調査では、日本・韓国・台湾・欧州・中国・米国など世界の関連企業を、上場市場や資料言語を理由に除外しない。ただし、特定の海外市場に固有のデータ取得手順、評価基準、通貨例は設けず、各社の公式IR・法定開示・取引所資料を優先する。

`$ARGUMENTS` の投資ポートフォリオを点検・最適化する。

**対応する入力形式**：
- 保有銘柄一覧。例：`トヨタ30%, ソニー20%, Apple20%, NVIDIA 15%, 現金15%`
- または：`トヨタ 500株 @3,000円, Apple 100株 @180ドル, ...`
- または：`私のポートフォリオ`（保存済みポートフォリオファイル `reports-jp/portfolio-latest.md` がある場合）

> 「分散投資は無知に対する防御である。自分が何をしているか理解しているなら、分散投資には意味がない。」――ウォーレン・バフェット
>
> 「私が生涯で見た本当に優れた投資機会は、両手の指で数えられるほどしかない。」――李録

## 設計思想

企業調査は投資の半分にすぎない。もう半分は**ポートフォリオ・レベルの意思決定**である：
- いくら買うか？（ポジションサイズ）
- 何の資金で買うか？（新規資金か、入れ替えか）
- 既存ポジションと競合しないか？（相関）
- 最適なポートフォリオはどのようなものか？（機会費用）

ウォーレン・バフェットは、1銘柄を単独では見ない。常に「これは自分ができる最良のことか？」と考える。

## 実行手順

### ステップ1：保有銘柄を解析する

入力から現在のポジションを抽出し、次の形式に標準化する：

| 投資候補 | コード | 保有数量 | 取得価格 | 現在値 | 時価総額 | 比率 | 損益 |
|------|------|--------|-------|------|------|------|------|

入力に比率だけがあり金額がない場合は、比率ベースで分析する。

同時に既存のポートフォリオファイル（`reports-jp/portfolio-latest.md`）があるか確認し、存在する場合は読み込んで更新する。

### ステップ2：最新データを取得する

TaskツールでバックグラウンドAgentを起動し、WebSearchを使って各ポジションについて並列で以下を取得する：
1. 現在の株価とバリュエーション指標（PER、PBR、配当利回り）
2. 直近四半期の重要な財務変化
3. 最近の重大イベント
4. アナリスト・コンセンサス（予想PER、目標株価）

各ポジションについて `tools/financial_rigor.py verify-valuation` でバリュエーションデータを検証する。各ポジションの情報の豊富さをA／B／C級で示し、C級の分析結論には低い確信度を付ける。

### ステップ3：個別ポジションの健康診断

各ポジションを迅速に点検する：

| 投資候補 | 現在のPER | 購入時の投資ロジックに変化があるか | 投資仮説の健全度 | ポジションサイズの提案 |
|------|:------:|:--------------:|:---------:|---------|
| トヨタ | 12倍 | 変化なし | 8/10 | 妥当 |
| Apple | 25倍 | 競争激化 | 6/10 | 高め。ポジション縮小を検討 |

各ポジションについて答える：
- [ ] **今日保有していなかったとしても、現在の価格で買うか？**
- [ ] **明日から取引できなくなっても、5年間安心して保有できるか？**
- [ ] **購入時の投資仮説は今も完全か？**

**段永平**：「株式を10年間保有したくないなら、1日も保有してはいけない。」

### ステップ4：ポートフォリオ・レベルの分析

#### 4.1 集中度分析

| 指標 | 現在値 | 推奨レンジ | 判断 |
|------|-------|---------|------|
| 最大ポジションの比率 | | 40%未満 | |
| 上位3ポジションの比率 | | 50～80% | |
| 保有銘柄数 | | 5～15銘柄 | |
| 現金比率 | | 10～30%（市場環境による） | |

**李録の基準**：中核ポジション3～5銘柄、上位3銘柄で80%以上。**ただし、各銘柄を徹底的に理解していることが前提である。**

**ウォーレン・バフェットの基準**：中核ポジションは10銘柄以下。ただし、サテライト・ポジションはより多くてもよい。

#### 4.2 相関の確認

ポジション間の隠れた関連を特定する：

| ポジションA | ポジションB | 関連の種類 | リスク |
|-------|-------|---------|------|
| Apple | Alphabet | デジタル広告・端末エコシステム | 規制と消費需要の共振 |
| NVIDIA | ASML | 半導体サプライチェーンの下流・上流 | AI設備投資と同方向に変動 |
| トヨタ | デンソー | 自動車メーカーと主要部品会社 | 生産台数と為替の同方向変動 |

**チェックリスト**：
- [ ] 同一テーマ／業界へのエクスポージャーがポジションの50%を超えていないか？
- [ ] 同一国／通貨へのエクスポージャーがポジションの50%を超えていないか？
- [ ] 米中関係が悪化した場合、ポートフォリオはどの程度損失を被るか？
- [ ] 世界経済が景気後退に入った場合、ポートフォリオはどの程度損失を被るか？

#### 4.3 機会費用の分析

これはウォーレン・バフェットの最も中核的な考え方である――**すべての資金を最も高いリターンが期待できる場所へ配分すべきである**。

全ポジションを「予想年率リターン」で順位付けする：

| 順位 | 投資候補 | 現在の比率 | 予想年率リターン | 確実性 | 予想リターン × 確実性 |
|:----:|------|:-------:|:----------:|:------:|:--------------:|
| 1 | | | | | |
| 2 | | | | | |
| ... | | | | | |

予想リターンの推計方法（`tools/financial_rigor.py three-scenario` で計算）：
- **簡易式**：予想年率 ≈ フリーキャッシュフロー利回り + 予想成長率（主な方法）
- **バリュー型の検証**：安全余裕の解消 + 利益成長率 + 配当利回り
- **成長型の検証**：利益成長率 × 妥当なPERの変化

**重要な問い**：最下位のポジションの予想リターンは、現金（無リスク金利約4%）を上回るか？ 上回らない場合は、売却して現金へ替えるべきである。

#### 4.4 ストレステスト

| シナリオ | 仮定 | ポートフォリオへの予想影響 | 最大ドローダウン |
|------|------|-----------|---------|
| 世界的な景気後退 | 企業利益が20～30%減少 | | |
| 地政学対立の激化 | 輸出規制と供給停止で対象企業の利益が大幅減少 | | |
| 金利急騰 | 10年国債利回りが6%へ | | |
| テクノロジー・バブル崩壊 | テクノロジー株のPERが40%縮小 | | |

各シナリオを定性的かつ概算で評価する（各ポジションの業界特性と過去のバリュエーション変動レンジに基づく）：
- どのポジションが最も大きな影響を受けるか？ おおよその方向と規模のレンジ
- ポートフォリオ全体で耐えられるか？
- ヘッジが必要か？

### ステップ5：最適化案

#### 5.1 ポジション調整案

上記の分析に基づき、具体的なポジション調整を提案する：

| 行動 | 投資候補 | 現在の比率 | 推奨比率 | 理由 |
|------|------|:-------:|:-------:|------|
| 買い増し | | | | |
| ポジション縮小 | | | | |
| 全売却 | | | | |
| 新規購入 | | | | |
| 変更なし | | | | |

#### 5.2 代替投資候補を探す

ポートフォリオに「現金より劣る」ポジションがある場合、または現金比率が高すぎる場合は、本Skill内で直接個別銘柄を推奨せず、`/industry-research` または `/investment-checklist` で関心のある業界／企業を体系的に選別するよう提案する。

#### 5.3 現金管理

| 現在の現金比率 | 推奨現金比率 | 理由 |
|:----------:|:----------:|------|

**ウォーレン・バフェット**：現在3,820億米ドルの現金を保有し、総資産の25%以上を占めている――良い機会が見つからないとき、現金は最良のポジションである。

### ステップ6：ポートフォリオ・レポートを出力する

#### レポート構成

```
1. ポートフォリオの概要（保有銘柄表 + 円グラフの説明）
2. 個別ポジションの健康診断（各ポジションの健全性）
3. ポートフォリオ分析
   - 集中度：過度に分散／集中していないか？
   - 相関：隠れた関連とリスクの共振
   - 機会費用：順位が最も低いポジションを保有する価値があるか？
   - ストレステスト：極端なシナリオでのドローダウン推計
4. ポジション調整案（具体的な行動 + 理由）
5. 次回の点検時期と注目点
```

#### 結論で必ず明確に答えること

1. **ポートフォリオ全体の健全度**：優秀 / 良好 / 調整が必要 / 重大な問題あり
2. **最も優先すべき行動は何か？**（Xを買い増し / Yを縮小 / 変更なし）
3. **現在の最大リスクは何か？**

### ステップ7：ポートフォリオファイルを保存する

ポートフォリオ情報を `reports-jp/portfolio-latest.md` に保存し、以下を含める：
- 最新の保有銘柄表
- 今回の点検日と結論
- ポジション調整の履歴（追記）
- 次回の点検リマインダー

## 重要原則

- **すべての資金には機会費用がある**――平凡な株式を保有するコストは、優れた株式を逃すこと
- **集中がリスクなのではなく、無知がリスクである**――深く理解した3銘柄を保有するほうが、よく理解していない30銘柄を保有するより安全
- **現金もポジションの1つ**――良い機会が見つからないとき、現金を保有することは恥ではない
- **ポートフォリオ・レベル > 個別銘柄レベル**――優れた株式でも、誤ったポジションサイズならポートフォリオの足を引っ張る
- **定期的に点検するが、過剰に取引しない**――四半期に1回の点検で十分。毎日相場を見てポジションを調整しない
