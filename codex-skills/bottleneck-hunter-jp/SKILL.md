# サプライチェーン・ボトルネックハンター（日本株版）

`$ARGUMENTS` で指定された巨大潮流について、供給網の制約を調べ、東証プライム・スタンダード・グロースに上場する内国普通株から投資候補を探す。

## 中心となる問い

「注目テーマの代表企業はどこか」ではなく、**この需要が拡大し続けたとき、最初に不足する物理的な工程・材料・設備は何か**を問う。完成品よりも、その一段、二段上流にある供給集中、長い増産期間、顧客認証、代替困難性を探す。

海外企業は日本企業の競合、顧客、供給先、技術経路を説明するためにだけ扱う。国外上場銘柄を候補化したり、価格・財務・評価を取得したりしない。

---

## 第1段階：テーマの確認

### 1.1 巨大潮流の条件

次の条件をすべて検証する。

| 条件 | 目安 | 検証方法 |
|---|---:|---|
| 持続性 | 3～5年以上 | 官公庁計画、企業の設備投資計画、業界予測 |
| 物理性 | 設備・材料・部品が必要 | ソフトウェア更新だけの需要と区別 |
| 規模性 | 国内で複数社の投資を動かす | 投資額、受注残、導入計画を集計 |
| 加速性 | 需要増加が供給増加を上回る | 需要成長率と能力増強の時期を比較 |

追跡候補には、AI基盤、電力網更新、脱炭素、防衛装備、半導体製造基盤、宇宙産業、工場自動化等がある。ただし固定リストを結論にせず、毎回最新資料で確認する。

### 1.2 確認結果

```text
テーマ名：
中心的な需要要因：
確認できた出来事（最低3件）：
  1. 日付／出来事／一次資料
  2.
  3.
国内投資規模と伸び率：
需要増加は供給増加を上回るか：はい／いいえ／不明
判定：追跡する／証拠不足で保留
不足情報：
```

証拠が不足する場合は、もっともらしい供給制約を作らず停止する。

## 第2段階：物理的な産業チェーンへの分解

概念語で止めず、物理的な品目・工程・認証まで分解する。

```text
Layer 0：最終製品・サービス
  └ Layer 1：中心部品・主要設備（注目が集中しやすい）
      └ Layer 2：副部品・材料（重点探索域）
          └ Layer 3：製造装置・原料・検査（重点探索域）
              └ Layer 4：電力・冷却・土地・技能・許認可・認証
```

各層について、国内の製造拠点、供給者、能力、増産計画、代替経路、顧客認証、輸入依存を表にする。検索では「不足」「納期」「増産」「採用」「値上げ」「供給制約」「単一供給」「認証期間」等を組み合わせる。

## 第3段階：6基準によるボトルネック判定

Layer 2～3の各工程を次の6基準で判定する。

| # | 基準 | 赤 | 黄 | 緑 |
|---:|---|---|---|---|
| 1 | 供給集中度 | 供給者2社以下 | 3～5社 | 6社以上 |
| 2 | 能力増強期間 | 2年超 | 1～2年 | 1年未満 |
| 3 | 代替困難性 | 代替不可 | 一部代替 | 容易 |
| 4 | 稼働率 | 90%超 | 70～90% | 70%未満 |
| 5 | 下流需要成長 | 年50%超 | 年20～50% | 年20%未満 |
| 6 | 顧客認証期間 | 1年超 | 6～12か月 | 6か月未満 |

- 赤が4項目以上：S級（単一障害点になり得る）
- 赤が3項目：A級（重大な制約）
- 赤が1～2項目：B級（圧力はあるが管理可能）
- 赤なし：候補から外す

根拠のない点数は付けない。不明項目は「不明」とし、S級・A級への格上げ理由に使わない。

```text
ボトルネック地図 — {テーマ}
基準日：YYYY-MM-DD
S級：工程／理由／国内供給者／根拠
A級：工程／理由／国内供給者／根拠
B級：工程／理由／国内供給者／根拠
前回比：新規／格上げ／格下げ／解消
```

## 第4段階：ボトルネックから日本企業へ

### 4.1 母集団

S級・A級工程について、東証上場会社情報、会社IR、EDINET、TDnet、業界団体資料から関連企業を漏れなく列挙する。対象は内国普通株に限り、ETF、REIT、外国株は除外する。

### 4.2 初期選別

| 条件 | 確認内容 |
|---|---|
| 純度 | 対象工程の売上・利益・受注への寄与。30%未満なら感応度を説明 |
| 供給地位 | 市場シェア、技術、認証、顧客採用、歩留まり |
| 流動性 | 売買代金、浮動株、出来高急減時の退出可能性 |
| 財務耐久力 | 現預金、純有利子負債、増産投資を賄う力 |
| 開示可能性 | 数値を一次資料で検証できるか |

### 4.3 評価は必須

**ボトルネックが本物でも、株価が魅力的とは限らない。** 各社について時価総額、売上高、営業利益、親会社株主に帰属する利益、PER、PBR、PSR、発行済株式数・自己株式数を確認する。

```bash
python tools/jpstock_data.py quote {証券コード}
python tools/jpstock_data.py financials {証券コード}
python tools/financial_rigor.py --locale ja verify-market-cap --price {株価} --shares {自己株式控除後株式数} --reported {照合対象の時価総額} --currency JPY
```

重要数値はEDINETまたは会社IRの一次資料と、JPXまたは別の独立経路で照合する。価格補助にyfinanceを使った場合は非公式値であると明記する。

#### 評価シグナル

- 赤信号：時価総額が到達可能市場の20%超、PSR 30倍超かつ売上成長100%未満、5年後の楽観売上高の10倍超、資金調達後60日以内の株価倍増。
- 黄信号：赤字かつPSR 15倍超、同業利益企業のPSRの5倍超、PER 80倍超。
- 緑信号：PSR 10倍未満かつ成長継続、またはPER 30倍未満で持続的な競争優位が確認できる。

赤信号が一つでもあれば信号強度は最大2つ星とする。黄信号は収益化の時期、利益率、成長鈍化時の評価を追加説明する。

#### 10年出口テスト

現在の時価総額で投資し、10年後にPER 25倍で退出して年率10%以上を得るために必要な純利益と売上高を逆算する。日本円で同一口径を使い、楽観シナリオでも10%未満なら「安全余地なし」と記す。確率加重による見せかけの精密さは使わない。

### 4.4 企業別の深掘り

```markdown
## {会社名}（{証券コード}）

### ボトルネック上の位置
- 工程、国内外シェア、顧客、認証状況

### 能力と増強
- 現有能力、稼働率、増産時期、必要資金、立ち上げリスク

### 財務スナップショット
- 時価総額、売上高、利益、成長率、対象事業比率、粗利率推移

### 日本固有の資本配分・統治
- 政策保有株、持合い、親子上場、支配株主、少数株主保護
- 自己株式取得・消却、DOE、株主優待、資本コストを意識した計画

### リスク
- 代替技術、顧客集中、希薄化、地政学、管理、供給地位の解消時期
```

## 第5段階：正方向と逆方向の交差検証

### 正方向

1. 顧客が採用・認証を開示しているか。
2. 受注、売上、粗利率、納期に供給制約が表れているか。
3. 値上げや長納期を業界資料が確認しているか。
4. 増産の設備投資と稼働時期が具体的か。
5. 少なくとも二つの独立情報源が同じ方向を示すか。

### 逆方向

1. 合理的な投資家が買わない理由は何か。
2. 代替材料、設計変更、内製化で回避できないか。
3. 新規参入や輸入増加で供給が急増しないか。
4. 最終需要が半減したときの利益と財務はどうなるか。
5. 過去の高値増資、転換社債、過大投資はないか。
6. 現在価格がすでに何年分の成長を織り込んでいるか。

反証が見つからない場合も「反証なし」ではなく、調べた範囲と情報盲点を書く。

## 第6段階：機会看板と一枚要約

| 順位 | 会社 | コード | 時価総額 | 売上高 | PSR | PER | 工程 | 等級 | シェア | 成長率 | 信号 | 評価 |
|---:|---|---|---:|---:|---:|---:|---|---|---:|---:|---|---|

時価総額、売上高、PSR、PERは必須。取得不能なら理由を書き、信号は最大2つ星とする。

- 5つ星：複数の確認、顧客採用、業績反映、評価は緑。
- 4つ星：大半を確認、評価は緑または説明可能な黄。
- 3つ星：論理は成立するが重要項目が未確認。
- 2つ星：初期信号、または評価が赤。
- 1つ星：概念だけで未検証。

## 第7段階：定期スキャンと状態更新

毎回、既存ボトルネックについて新規供給者、能力増強、代替技術、認証、需要鈍化を確認し、新しい不足も探索する。前回からの格上げ・格下げ・解消を理由付きで記録する。

保存先：

- `reports/bottleneck-map/master-map.md`：全体地図
- `reports/bottleneck-map/watchlist.md`：監視企業と条件
- `reports/bottleneck-map/YYYY-MM-DD/`：日次の調査結果
- `reports/bottleneck-map/deep-dive/`：個別企業の深掘り

既存ファイルがある場合は読み込み、履歴を失わない形で追記する。別版として保存する場合は日付を付け、無断で上書きしない。

### 毎時スキャンモード

1. 直近1～2時間の不足、能力、納期、値上げのニュースを探す。
2. 監視企業の5%超の価格変動と出来高を確認する。
3. TDnetと会社IRの決算・適時開示を確認する。
4. 監視企業が事前の買い条件に入ったか確認する。
5. 新信号、明確な候補、重大な状態変化があるときだけ報告を作る。何もなければログに「新規信号なし」とだけ残し、報告ファイルは作らない。

ファイル名：明確な候補がある場合は `HH-MM-{コード}-{コード}.md`、信号のみなら `HH-MM-信号スキャン.md`。

```markdown
# ボトルネックハンター — YYYY-MM-DD HH:MM

## 明確な候補
### {会社名}（{コード}）
- 今回の契機
- ボトルネック位置と等級
- 財務スナップショット
- 評価信号と10年出口テスト
- 強気論点／弱気論点
- 次の行動

## その他の新信号
```

## 監査と失敗時処理

公開可能とする前に実行する。

```bash
python tools/report_audit.py --locale ja extract --report {レポートパス} --market jp
python tools/report_audit.py --locale ja verdict --results '<照合済みJSON>' --report {レポート名} --market jp
```

- 数値不一致：一次資料の定義・期末・連結／単体・日本基準／IFRSを揃えて再計算する。
- 検索失敗：確認できた資料、試した検索、欠落項目を記し、評価を下げる。
- 監査不合格：公開稿にせず、失敗項目を直して再監査する。
- 出典なし：事実ではなく仮説として明示するか削除する。

## 認知上の偏り

| 偏り | 症状 | 対策 |
|---|---|---|
| 大型株偏重 | 検索上位だけを見る | 小型・中型の供給者も工程から逆引き |
| 物語偏重 | テーマ名だけで採用 | 実物、能力、納期、認証を見る |
| 確認偏重 | 強気材料だけを集める | 逆方向の6問を必須化 |
| 新しさ偏重 | 一時的な不足を恒久視 | 前回地図と能力増強時期を比較 |
| 小型株礼賛 | 小さいだけで割安とみなす | 財務耐久力と評価を硬い門にする |

## 最優先原則

1. 推薦から始めず、物理的な供給網から始める。
2. 第二層・第三層の見落とされた制約を探す。
3. 重要結論は二つ以上の独立情報源で確認する。
4. ボトルネックには期限がある。解消条件を必ず書く。
5. ボトルネックの真実性と投資価格の魅力を分ける。
6. 不明を推測で埋めない。
7. 先にデータ、次に論理、最後に結論とする。
